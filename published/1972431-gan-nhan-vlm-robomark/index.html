1. Lời nói đầu & Quá trình phát triển

Xin chào tất cả các RMer, chúng tôi là đội AIM đến từ Đại học Nottingham Ninh Ba (UNNC). Gần đây, chúng tôi đã đóng gói và hoàn thiện bộ công cụ gán nhãn hình ảnh do chính đội mình phát triển mang tên RoboMark, xin được chia sẻ công khai cho các đội thi có nhu cầu sử dụng.

Năm ngoái, khi tôi bắt đầu chuẩn bị công việc cho nhóm thị giác, dự án Radar của đội vẫn chỉ nằm trên GitHub và chưa có giải pháp xử lý thị giác cụ thể nào. Vào khoảng tháng 1 năm ngoái, khi các công cụ AI thế hệ mới bắt đầu bùng nổ, tôi đã suy nghĩ làm thế nào để việc gán nhãn dữ liệu (labeling/annotation) trở nên nhẹ nhàng hơn.

Quá trình hoàn thiện công cụ đã trải qua nhiều giai đoạn:

  • Thử nghiệm đầu tiên: Một script Python đơn giản dùng mô hình YOLO thô quét qua thư mục ảnh, sau đó hiện cửa sổ pop-up kiểm tra độ chính xác và chọn phím tắt để phân loại.
  • Giai đoạn giao diện kéo khung: Bắt đầu bằng giao diện desktop đơn giản viết bằng Tkinter và OpenCV. Tuy nhiên nó chỉ cho phép kéo khung chữ nhật, rất bất tiện khi cần đổi nhãn hoặc sửa nhãn.
  • Chuyển dịch lên nền tảng Web: Bản prototype đầu tiên dùng ElementPlus, sau đó được tái cấu trúc giao diện bằng Shadcn UI hiện đại, bổ sung hàng loạt tính năng công thái học, tải trước ảnh (preloading) và đồng bộ dữ liệu nhóm.

各位 RMer 大家好，这里是宁波诺丁汉大学 AIM 战队。最近把我们做的一套图像标注工具整理了一下，叫 RoboMark，分享出来给有需要的队伍。去年我开始准备视觉组的工作的时候，我们是一个雷达停留在 GitHub 上的项目。去年一月份是 Claude Code 刚开始大显神威的时候，借着实习的时候有无限的当时最强的 Opus 能用，我在思考如何让打标变得更容易一点。第一次尝试是分类，一个很简单的 Python 脚本... 然后开始需要拉框，一开始是一个很简单的 Tkinter 和 OpenCV 的桌面 UI... 然后发现，fine，那我们上 web 吧。

Hình 1: Một đợt gán nhãn sơ bộ thực tế trên dataset giáp robot DJI-Armor-QDU. Khung ứng viên, trạng thái xử lý, trạng thái duyệt và dung lượng token hiển thị ngay trên cùng 1 thẻ.

2. Quy trình làm việc tổng thể

RoboMark là một nền tảng Web có thể tự triển khai độc lập (self-hosted). Một dataset từ lúc nhập vào cho đến lúc xuất ra huấn luyện sẽ trải qua luồng chuẩn:

Nhập thư mục ảnh ➔ Cấu hình nhãn ➔ Gán nhãn thủ công / VLM gán nhãn sơ bộ ➔ Kiểm duyệt thủ công ➔ Xuất dữ liệu huấn luyện

Nếu bạn chỉ muốn gắn nhãn thủ công: Không cần GPU, không cần cấu hình AI. Chỉ cần tạo tập dữ liệu, danh mục nhãn là có thể vào làm việc ngay trên trình duyệt.

Bảng tổng hợp các tính năng chính:

Khâu thực hiện Tính năng có sẵn
Quản lý dữ liệu Hỗ trợ nhiều dataset, quét thư mục server, xem trước ảnh, thống kê tiến độ, bật/tắt tập dữ liệu.
Quản lý nhãn (Class) Màu sắc nhãn, phím tắt, sắp xếp thứ tự, import hàng loạt, gắn kèm ảnh mẫu tham khảo (reference template).
Gán nhãn thủ công Khung chữ nhật (BBox), tứ giác 4 điểm / 8 điểm, kéo giãn điều chỉnh, thu phóng/di chuyển, Undo/Redo, hàng đợi ảnh.
Kết nối mô hình AI Chuẩn vLLM / OpenAI API, HTTP JSON tùy biến, ánh xạ trường dữ liệu (field mapping), chuyển đổi tọa độ, kiểm tra kết nối.
Gán nhãn sơ bộ (Pre-annotation) Hỗ trợ Prompt tùy biến, chế độ chạy thử mẫu nhỏ rồi mới chạy toàn bộ, tiến trình chạy nền độc lập (worker), hủy/thử lại bài lỗi.
Kiểm duyệt kết quả (Review) Xếp lớp khung AI (nét đứt) và khung duyệt (nét liền), lọc theo trạng thái, lưu nháp (draft), duyệt đạt (accept) / từ chối (reject).
Truy vết sự cố (Traceability) Lịch sử gửi request từng ảnh, raw response từ mô hình, mã lỗi, đo lường Token và tốc độ TPS.
Xuất dữ liệu & Phân quyền Xuất chuẩn Ultralytics YOLO, Darknet, COCO JSON, chia tỷ lệ train/val/test, tải file ZIP, phân quyền Admin/Member.
Xem nguyên văn tiếng Trung (原文)

RoboMark 是一套可以自己部署的 Web 标注平台。一个数据集从进来到导出，大致是下面这个流程：导入图片目录 → 配置类别 → 人工标注 / 模型预标注 → 人工审核 → 导出训练数据。如果只想手工标图，不需要先配模型，也不需要 GPU。目前主要功能包括数据管理、类别管理、人工标注、模型接入、批量预标注、结果审核、排查问题与导出管理。

Hình 2: Trang tác vụ gán nhãn AI. Bên trái cấu hình endpoint, nhãn mục tiêu và System Prompt; bên phải theo dõi batch chạy thử và toàn bộ batch.

3. Kết quả đánh giá thực tế các mô hình AI

Chúng tôi đã thử nghiệm thực tế trên tập dữ liệu DJI-Armor-QDU (404 ảnh giáp xe robot của ĐH Thanh Đảo):

  • Claude 3.5 Sonnet: Cho độ chính xác và khả năng bắt viền mép giáp tốt nhất, tuy nhiên chi phí token quá đắt đối với các đợt cào hàng nghìn ảnh.
  • GLM-5.3-Flash: Là lựa chọn có tỷ lệ hiệu năng / giá thành (P/P) cao nhất hiện nay, nhận diện rất tốt các dải đèn LED và tấm số trung tâm của giáp robot.
  • Lưu ý: Kết quả AI trả về chỉ là "khung ứng viên". Con người vẫn là khâu kiểm soát cuối cùng để sửa các góc lệch, tránh tình trạng mô hình bắt nhầm đèn trần sân đấu hoặc vệt phản chiếu sàn thi đấu.
Xem nguyên văn tiếng Trung (原文)

在这里我们尝试了常用的几款拥有视觉识别模式的大模型，抛开成本不谈运行效果最好的是 Claude Sonnet 3.5, 但是这很显然太贵了。综合性价比最高的是 GLM-5.3-flash，而 Deepseek V4.1 Flash 完全没有遵循 System 中声明的输出格式...

Hình 3: Giao diện kiểm duyệt. Khung AI vẽ hiển thị nét đứt, khung người duyệt vẽ hiển thị nét liền. Bấm Ctrl + Enter là duyệt và tự chuyển sang ảnh kế tiếp.

5. Hướng dẫn tự cài đặt trên Server nội bộ

Yêu cầu môi trường:

  • Python 3.10 trở lên
  • Node.js 20.19+ hoặc 22.12+
  • Cơ sở dữ liệu MySQL 8.0+
  • Dung lượng ổ cứng đủ lớn để chứa ảnh dataset

Các lệnh cài đặt:

git clone https://github.com/unnc-aim/RoboMark.git
cd RoboMark

# 1. Khởi tạo cơ sở dữ liệu
mysql -u root -p < database/init.sql

# 2. Cấu hình biến môi trường
cp backend/.env.example backend/.env
# Chỉnh sửa thông số trong backend/.env

# 3. Khởi động môi trường (API, worker và Frontend)
./dev.sh
