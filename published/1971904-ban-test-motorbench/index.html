Nguồn tham khảo: RoboMaster BBS

📦 Tài nguyên & Tải phần mềm

  • Mã nguồn mở trên GitHub: https://github.com/wbz2006/RM-MotorBench ↗
  • Bản cài đặt Desktop Windows: MotorBench-1.2.0-Windows-x64.exe ↗ (Chạy trực tiếp, không cần cấu hình Node.js hay Python)
  • Dòng động cơ hỗ trợ: DJI M3508, DJI M2006, DJI GM6020, Damiao DM4310, DM8009P.

1. Bài toán: Nỗi ám ảnh nạp code khi test động cơ

Khi thiết kế cơ cấu robot (như cơ cấu cấp đạn, bệ gimbal, cụm bánh đà hay cơ cấu kẹp), khâu thử nghiệm động cơ thường tốn rất nhiều thời gian lãng phí:

  • Mỗi lần đổi động cơ hoặc đổi ID CAN, kỹ sư phải mở IDE, sửa code, biên dịch lại rồi nạp lại firmware.
  • Khó quan sát trực quan đồ thị đáp ứng bước nhảy (Step response) và độ vọt lố (Overshoot) khi căn chỉnh PID.
  • Rủi ro sai lệch ID bus CAN gây va chạm lệnh giữa các thiết bị.

2. Giải pháp RM-MotorBench: Test động cơ qua Web UI không cần nạp lại code

Tôi thấy giải pháp của RM-MotorBench giải quyết trọn vẹn vấn đề này: Người dùng chỉ cần nạp firmware tổng quát một lần duy nhất vào bo điều khiển. Toàn bộ thao tác sau đó được thực hiện trực tiếp trên giao diện Web UI:

  1. Giao thức giao tiếp: Máy tính kết nối với bo mạch qua cổng ảo USB Virtual COM (CDC). Các lệnh cấu hình và điều khiển được gửi xuống bo mạch với độ trễ dưới 2ms.
  2. Tự động điều phối CAN bus: Bo mạch phân tích lệnh và tự động khởi tạo node điều khiển trên bus CAN tương ứng với ID gạt mã của ESC mà không cần biên dịch lại firmware.
  3. Phản hồi telemetry thời gian thực: Tốc độ vòng quay (RPM), dòng điện tiêu thụ (A), vị trí góc và nhiệt độ động cơ được gửi ngược lên máy tính và vẽ biểu đồ trực tiếp.

Hình 1: Mô hình bàn test thực tế tại phòng Lab

3. Các tính năng kỹ thuật nổi bật

  • Hỗ trợ đa dạng phần cứng: Firmware mã nguồn mở (CubeMX + CMake) sẵn sàng cho 3 dòng bo mạch thông dụng: DJI Type A, DJI Type C và Damiao MC02; tất cả dùng chung một Host UI.
  • Chuyển đổi 3 vòng điều khiển trực tiếp (Vận tốc / Vị trí / Dòng điện): Căn chỉnh thông số PID ngay trên giao diện web và ghi tức thời vào vòng lặp điều khiển.
  • Bộ công cụ đo kiểm chuyên dụng:
    • Vẽ đồ thị đáp ứng thời gian thực với tần số lấy mẫu cao.
    • Tự động phát tín hiệu kích thích hình Sin hoặc sóng bước nhảy (Step wave) để nhận dạng hệ thống.
    • Công cụ tính toán quy đổi giữa tần số cơ cấu sang số vòng quay/phút của động cơ.
  • Cơ chế an toàn phòng ngừa hư hại:
    • Nhịp tim bảo vệ (Heartbeat timeout): Nếu mất tín hiệu kết nối máy tính quá 1.5 giây, bo mạch lập tức ngắt toàn bộ lệnh điều khiển để chống trôi tự do.
    • Phím dừng khẩn cấp (E-Stop): Nhấn phím cách (Spacebar) ngắt lực tức thì khi cơ cấu bị kẹt tải.

Hình 2: Chi tiết các vùng chức năng trên phần mềm điều khiển Host UI

4. Hướng dẫn thiết lập & thao tác nhanh

  1. Nạp firmware bo mạch: Dùng VS Code với extension STM32CubeIDE, mở thư mục dự án tương ứng với bo mạch đang có (Type A / Type C / MC02) và nhấn F5 để nạp.
  2. Khởi chạy Host UI trên máy tính:
    • Cách nhanh nhất: Tải file MotorBench-1.2.0-Windows-x64.exe về mở trực tiếp.
    • Cách chạy từ nguồn: Mở terminal, gõ npm install && npm start rồi truy cập http://127.0.0.1:3000.
  3. Kết nối & điều khiển:
    • Chọn cổng COM tương ứng của bo mạch.
    • Bấm ＋ Thêm động cơ $\rightarrow$ Chọn Model (M3508 / M2006 / GM6020 / DM4310) $\rightarrow$ Chọn Bus CAN (CAN1 / CAN2) $\rightarrow$ Điền ID gạt mã của ESC.
    • Bấm Bind (Liên kết) $\rightarrow$ Bấm Enable (Kích hoạt) $\rightarrow$ Kéo thanh trượt để test tốc độ và xem đồ thị phản hồi.

5. Lưu ý thực tế về phần cứng và an toàn điện

⚠️ Kinh nghiệm thực chiến khi đấu nối bàn test:
  • Luôn kiểm tra chiều phân cực jack nguồn XT30 / XT60 trước khi bật nguồn 24V (cắm ngược cực sẽ cháy nổ chip nguồn và driver).
  • Đảm bảo bus CAN có trở đầu cuối 120Ω để tránh phản xạ sóng làm mất gói dữ liệu CAN ở tốc độ cao (1 Mbps).
  • Khi bắt đầu thử nghiệm cơ cấu mới, luôn giới hạn trần dòng điện (Current Limit) ở mức thấp để tránh làm gãy bánh răng nếu cơ cấu bị kẹt.

6. Giới hạn cần lưu ý khi sử dụng

  • Danh sách động cơ đã gán trên Web hiện tại không lưu vào bộ nhớ ROM của bo mạch, do đó khi mất nguồn hoặc rút cáp USB bạn sẽ cần bấm thêm lại trên Web.
  • Thông số PID mẫu chỉ là tham khảo cho trạng thái không tải; khi lắp vào tải cơ khí thực tế (bánh đà quán tính lớn, cánh tay đòn), cần tinh chỉnh lại hệ số $K_p$, $K_i$, $K_d$ phù hợp.
