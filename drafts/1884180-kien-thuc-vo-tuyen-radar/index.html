1.项目介绍

1.1 项目简介：

本项目为南京理工大学江阴校区 Combat 战队 2026 赛季雷达解析信息波部分，覆盖干扰波接收、信息波接收、协议编解码、波形生成、频点参数配置以及与主程序服务器的联动通信。本项目仅需要一块pluto sdr模块可实现对干扰波和信息波的接收，在开启gui_launcher.py时，东部赛区实测稳定解析2次干扰波，但信息波解析率较低（大概率是由于信息波和干扰波功率相差较大而信息波被覆盖，实测比赛开始和结束时都能接收到几帧信息波数据）。安装python依赖后即可部署。

雷达解析信息波作为今年提出的新规，雷达组成员也只是出于摸索阶段，水平有限，旨在开源已经在赛场上实际验证可行的sdr方案，存在诸多不足的地方请大家多多包涵，仅供参考，并提醒sdr使用请遵守国家法律法规，不承担任何他人使用不当造成的不良后果，希望能给各位RMer带来一些帮助！

1.2 硬件选型：

整个开发周期共使用了三个sdr，均为基于移植pluto-fw-v0.38固件的成品模块，与运算端均采用5m长千兆网线通讯，同时采用一根5m双typec带有信号放大器的数据线连接板卡上的usb口与运算端用于识别连接pluto设备以及供电（实测用普通5m数据传输线信号衰减较严重，运算端无法稳定连接上sdr设备）。天线方面由于我们是将设备放置在官方发射源旁，信号功率较强，利用商家赠送的拉杆天线垂直极化也可稳定接收，水平有限，对于天线没有较多研究，不过天线确实很值得研究，有助于提升接收的上限，可以参考其他相关的开源项目。

第一块板卡为7020+AD9361/AD9363 pluto sdr卡,也是比赛时采用的接收板卡，详细参数请参考商品页面

1.3 软件需求:

  • Python3.9
  • Windows10、Linux（Ubuntu支持，其他Linux系统可能需要适配）

比赛时使用Ubuntu22.04,pip install requirements.txt中所含库即可直接运行。

1.4 实战效果：


由于前几场比赛参数配置有误，导致前几场雷达没有正常运行，还有几场在测试信息波解析在不同等级干扰波下的解析能力，实测可以稳定解析两次密钥，在赛场干扰波环境下难以解析信息波。
