2. 功能说明

  1. 制作简单的飞书问卷并置顶与飞书显眼处（群标签栏/群置顶），为简化流程，我们仅设置了几个必备要素，考虑填写问卷成本和发聊天信息一样简单，填写后飞书将自动储存后台和补充其他预置信息于多维表格中（后面会详细写配置教程）。

  1. 填写后，飞书机器人将自动将任务发布提醒同时发到“任务管理群”内以及执行人的私信中，并在任务链接下方显示完成点击按钮（展示效果1/2），在任务完成后点击，“任务管理群”及发布者私信将获得任务完成提醒（展示效果1/2），若任务未完成，执行人将于每日固定时间收到“任务未完成”的提醒信息（展示效果3）。
  2. 自动存进多维表格后台，通过服务器调用飞书开放平台API，读取数据，并制作网页，网页中加入排行榜功能提高趣味性，并加入Github数据滚动显示，提高界面观赏性，通过校园网，显示在实验室的触摸屏中，用于日常任务公示。
  3. 解决痛点：
  • 私信提醒任务后可能存在忘记的情况
  • 队长、项管和组长对在办任务了解不全面，公式出可便于提醒
  • 任务完成后，完成人忘记提醒，导致发布者以为任务未完成
  • 私信导致项目进度可能会由于执行者时间安排受限，其他人并不知道任务需要完成
  • 后台有记录功能，便于回溯问题
  • 屏幕展示任务完成情况，提高完成积极性
  • 屏幕可添加公共材料（如知识库、规则)查询等功能，可拓展性高

3.3自制帅帅的前端网页

现在AI比较发达，大家可以根据自己需求调取飞书API读取数据进行显示，前端调试成本比较低，问题也容易定位，大家可以自由DIY。

第一步：打开飞书获取权限

   1. 前往 飞书开放平台 创建一个“自建应用”。[https://open.feishu.cn/app/]

   2. 在“添加应用能力”中添加“机器人”

   3. 在“权限管理”中，点击蓝色“开通权限”，给这个应用开通 “查看、评论、导出和管理多维表格” (bitable:app) 或至少可读的权限以及获取飞书头像的“获取用户基本信息” (contact:user.base:readonly) 权限。

   4. 在你的飞书多维表格中，点击右上角的“分享” -> “添加协作者”，把刚才创建的机器人/应用添加进去（给阅读权限即可），否则代码没有权限读取这个表。（如果建群，就把机器人拉进群里）

   5. 在“凭证与基础信息”中获取 App ID 和 App Secret。（后面代码里要调用)

   6. 发布应用

第二步:在服务器里配置环境（如果在本机配置参考3.4）

  1. 在服务器上新建一个文件夹（例如命名为 dashboard），然后创建 api.php 和 index.php 两个文件。

放在/var/www/html/dashboard里

  1. 安装 PHP 和 cURL 扩展
# 更新软件源
sudo apt update

# 安装 Apache Web 服务器、PHP 主程序以及 cURL 扩展
sudo apt install apache2 php libapache2-mod-php php-curl

# 重启 Apache 让扩展生效
sudo systemctl restart apache2
  1. 启动 Web 服务

在终端中，cd 进入你存放这两个文件的 dashboard 目录：

cd /你存放文件的路径/dashboard/

启动 PHP 内置服务器（绑定 0.0.0.0 意味着允许局域网内其他设备访问，这里假设使用 8080 端口）：

使用nohup是为了后台一直运行。

nohup php -S 0.0.0.0:8080 > dashboard.log 2>&1 &
  1. ⚠️ 最关键的一步：赋予写入权限

我们的 api.php 会在同级目录下自动生成一个 github_org_cache.json 的缓存文件。

在 T620 的终端里，执行以下命令，把该目录的拥有者交给 Web 服务器（Apache 默认用户通常是 www-data）：

# 假设你的代码放在 /var/www/html/dashboard 目录下
sudo chown -R www-data:www-data /var/www/html/dashboard
sudo chmod -R 755 /var/www/html/dashboard

（如果嫌麻烦，在内网安全的实验室环境下，直接简单粗暴给个读写权限：sudo chmod 777 /var/www/html/dashboard 也是可以的。）
