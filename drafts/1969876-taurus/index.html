一、前言

本次开源整理了华南农业大学 Taurus 战队 2026 赛季工程机器人机械臂嵌入式控制与运动学相关工作，包含 MATLAB 任务空间验证、七自由度解析逆运动学、重力补偿及柔顺控制等内容。

相关代码、算法推导与测试结果见下方 GitHub 仓库及技术报告。

二、开源资料

1. GitHub 代码仓库

TaurusArm：

https://github.com/hurry-debugger/TaurusArm

仓库包含 MATLAB 完整验证代码，以及七自由度机械臂运动学、重力补偿等 STM32 核心算法代码。

其中 C 部分以关键算法开源为主，不包含完整整车工程、通信、电机驱动及比赛业务代码。仓库 README 中已经给出了目录结构、环境依赖与移植说明。

2. 技术报告

《华南农业大学 Taurus 战队 2026 赛季工程机器人嵌入式控制开源》

华南农业大学Taurus战队2026赛季工程机器人嵌入式控制开源.pdf

报告共 22 页，包含机械臂 MATLAB 离线验证、七自由度解析逆运动学推导、STM32H723 实测、重力补偿以及关节空间柔顺控制等内容。
