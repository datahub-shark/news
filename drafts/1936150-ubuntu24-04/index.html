一，问题描述

我们队在使用华硕NUC15 ubuntu24.04时出现了小电脑开机时频繁卡死在开机页面长时间等待无法进入系统的问题，小电脑开机成功概率不高。考虑到这个问题可能不止我们会遇见且影响巨大，遂发布此帖提醒大家。

二，问题定位

这个问题是由海康相机驱动MVS的gevfilter模块与ubuntu24.04于5月底发布的6.17.0-35的HWE内核版本导致的。

调取Ubuntu日志，我发现Kernel boot时硬件初始化正常，但是在InitModuleService加载gevfilter模块时，gevfilter module access invalid memory并且加载失败，后续系统尝试重新加载均失败，并且导致CPU长时间卡死并且触发soft lockup。

检查内核版本，发现内核在没有手动更新的情况下，unattended upgrade自动更新（security）至6.17.0-35版本。根据apt日志，是在六月十七日自动更新的，此问题也是在六月十七日后多次出现的。初步定位是内核版本变更导致的。

验证问题定位。我们此前一直使用6.17.0-20版本内核，尝试回退回此版本内核，测试发现此问题确实没有再复现。虽不够严谨，但我力所能及的探索也仅限于此了，附件附上我当时截取的错误log，欢迎大家查看讨论。

三，问题解决

我们目前采用回退到6.17.0-20版本解决并且禁用自动更新的方式解决。

禁用unattended upgrade:

执行

sudo nano /etc/apt/apt.conf.d/20auto-upgrades

修改为

APT::Periodic::Unattended-Upgrade "0";

回退内核版本：

我们选择6.17.0-20版本仅是因为在构建今年的新工作空间时配合openvino 2026年1月版本时采用的是此版本，且经过1月到5月的使用没有出现此问题。

温馨提醒，在回退时最好在清除其他版本内核镜像前，安装好linux-modules-extra-<版本号>-generic，因为NUC配套的网卡容易调驱动，而且是手机共享网络都无法正常识别的，除了重装或者手动下载安装包以外没有什么好方法。

安装6.17.0-20版本：

sudo apt install linux-image-6.17.0-20-generic linux-headers-6.17.0-20-generic linux-modules-6.17.0-20-generic linux-modules-extra-6.17.0-20-generic

修改GRUB：

sudo nano /etc/default/grub
GRUB_DEFAULT="Advanced options for Ubuntu>Ubuntu, with Linux 6.17.0-20-generic"

更新GRUB：

sudo update-grub

四，问题思考

我负责队内的无人机算法，在比赛过程中遇到的最大问题是，小电脑开机时容易出现开机时间过长。我们今年通过加入灯语和蜂鸣器来监控小电脑和主控版的状况，对上电后的每一步都严格计时，一旦超时立马重启。

在分区赛前排除了很多问题，保证了小电脑在那段时间稳定正常开机，但在分区赛时，我们出现了三次开机时间过长，且赛后找不到原因，排查了很多方向还是没有头绪。

赛后遇到这个问题还算是可复现可溯源的，解决了还算令人欣慰。
