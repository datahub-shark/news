练习目标

通过下面的学习，你将学会设计一个滤波器，将下面含有两个频率分量的频率提取出低频信号。

一、使用MATLAB fdatool设计滤波器

基础页面认识

  • 在MATLAB中的 命令行 输入 fdatool，打开滤波器设计器。

观看我们采样信号的频率分量，很明显，噪声是高频率的小信号，且振幅远小于主频率信号振幅（传统滤波器滤波实际上是压小不需要频率的振幅，不可能完全滤除，所以传统滤波器的局限性就是对于噪声幅值较大的信号，滤波效果不太理想，后续教程将说明）.

  • 因此选取低通滤波器, 为后续考虑, 选择截止频率为30Hz. (实际使用中建议通过fft获取信号频率, 再给出截止频率选取)
  • 在左下区域选择第一个选项低通, 下面选择IIR滤波器, 选择巴特沃斯滤波器, 阶数设置默认最小阶.

下面的表格给出IIR, FIR, 以及巴特沃斯等模型的区别.

特性FIR 滤波器IIR 滤波器
反馈结构无反馈（非递归）有反馈（递归）
相位特性可严格线性相位非线性相位
达到相同指标阶数高（需数百阶）低（通常 4~8 阶）
特性巴特沃斯切比雪夫Ⅰ型切比雪夫Ⅱ型椭圆滤波器
通带特性最平坦（无纹波）等波纹无纹波等波纹
阻带特性单调下降单调下降等波纹等波纹
过渡带陡峭度最缓中等中等最陡
达到相同指标所需阶数最高较低较低最低
相位非线性较平滑严重严重最严重

根据上面表格，我们选取IIR滤波器的原因在于：IIR阶数低，资源消耗低，本测试环境中不怎么考虑相位畸变。

选取巴特沃斯原因：我们希望能够完美滤除噪声高频信号，不要产生纹波。

  • 在 频率设定 中，选取 Fs (采样频率) 为1000Hz，$F_{pass}$ 为15，$F_{stop}$ 为50. (因为模拟滤波器和理想滤波器是有差距的，理想滤波器的频域图为一个阶跃，但是模拟的频域图为一个斜着的台阶，这两个参数就是这两个台阶下降到0.707 和 0.1 的截止频率)，这两个数设置过程中保证平均值在你的理想截止频率左右即可。
  • 后面的幅值设定，是通带阻带的振幅压缩倍率，默认即可，我们选择改成20以减小阶数。
  • 点击最下面的设计滤波器，滤波器的幅频图就显示出来了，注意纵轴单位为dB.
  • 为了简化计算，我们选择一阶串联型。按照下面图片选择1->2->3，其中2选项选择第一个 直接1型 ，注意转化后是否稳定，若不稳定可以考虑增大过渡带频率或者增大A_stop。

  • 图片中3选项，选择第一个 生成C头文件，保存至代码中即可。（这就是卷积所使用的参数）。

卷积代码


#include "main.h"
#include "iir.h"

const int NL = 6;
const double NUM[6] = {
  8.128524167437e-07,4.064262083718e-06,8.128524167437e-06,8.128524167437e-06,
  4.064262083718e-06,8.128524167437e-07
};
const int DL = 6;
const double DEN[6] = {
                   1,   -4.592519754058,     8.45186748933,   -7.790520040485,
      3.596249128499,   -0.665050812009
};


typedef struct
{
    double xhist[6];  // 改为double保持精度
    double yhist[6];  // 改为double保持精度
    double y;
} Filter_t;

Filter_t filter = {
    .xhist = {0},
    .yhist = {0}
};

// /*  hz=DEN/NUM
//     使用直接型差分方程实现：
//  *  y[n] = sum_{k=0..NL-1} NUM[k]*x[n-k] - sum_{k=1..DL-1} DEN[k]*y[n-k]
//  */
double butterOrdF(float input)
{
    double input_d = (double)input;  // 转换为double
    
    // 更新历史缓冲区
    for (int i = NL-1; i > 0; i--)
    {
        filter.xhist[i] = filter.xhist[i-1];
    }
    filter.xhist[0] = input_d;
    
    for (int i = DL-1; i > 0; i--)
    {
        filter.yhist[i] = filter.yhist[i-1];
    }
    
    // 计算分子部分 (与输入历史卷积)
    double numerator = 0.0;
    for (int k = 0; k < NL; k++)
    {
        numerator += NUM[k] * filter.xhist[k];
    }
    
    // 计算分母部分 (与输出历史卷积)
    double denominator = 0.0;
    for (int k = 1; k < DL; k++)  // 从1开始，因为DEN[0]=1
    {
        denominator += DEN[k] * filter.yhist[k];
    }
    
    // 计算当前输出: y[n] = numerator - denominator
    filter.yhist[0] = numerator - denominator;
    filter.y = filter.yhist[0];
    
    return filter.y;
}

Q1：为什么要写这个？当前谁还用这些老掉牙的东西？

A1：你知道你常用的算术平均值滤波其实是低通滤波吗，你知道他的通带阻带可以计算吗，你知道算术平均滤波的长度决定什么吗。这是我在组员间的交流中得知，绝大多数新生还是不知道的，因此本仓库主要做的是启蒙，帮助要学习滤波器设计的同学。

Q2：学习这个有什么用？

A2：引用玺佬的一句话：知识从来都不是孤立的。学习完传统滤波器设计后，你就可以尝试学习经典控制理论中的频率法，进而正式入门控制学科。现代滤波器部分，你就会发现滤波从另一个角度来考虑问题，能补充传统滤波器的不足。
