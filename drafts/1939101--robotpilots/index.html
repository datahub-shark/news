一、 项目背景与方案设计

在 RoboMaster 比赛中，能量机关击打距离通常在 7 米左右。在远距离下，纯深度学习预测关键点容易因像素级抖动导致 PnP 解算误差偏大，难以稳定保证极高环数。

因此，我们采用了 「深度学习（YOLOv8-Pose）初定位 + 传统视觉几何精细解算」 的结合方案：

•深度学习网络：负责抗复杂光照/高曝干扰，高鲁棒性地输出符叶类别、4 个装甲板角点和 1 个 R 标中心；

•传统视觉算法：在网络给出的 ROI 和初值基础上进行亚像素级边缘提取与几何拟合，极大提升了 7 米打符的命中率与稳定性。

在比赛中取得不错的效果

二、 模型规格与核心亮点

1.网络架构：

◦结构原型基于 YOLOv8，使用 YOLOv8n-pose 预训练骨干网络；

◦针对能量机关场景进行了轻量化定制，在保证关键点稳定性的同时极大降低误识别并提升速度。

2.画幅匹配与 0 Padding 极速设计：

◦相机输入分辨率：1440 × 1080（标准 4:3）；

◦网络输入分辨率：640 × 480（同为 4:3）；

◦训练数据集统一采用 480 × 640。由于画幅比例完全一致，Resize 阶段无需添加任何上下/左右黑边填充（Zero Padding），消除了冗余计算，大幅提高端到端速度。

3.模型输入输出规格：

◦输入：1 × 3 × 480 × 640 (RGB)

◦输出张量：1 × 18 × 6300

◦18 个通道组成：3 类别置信度 + 5 个关键点 × 3 维 (x, y, conf)

◦3 类别定义

▪类别 0：未激活（inactive，大/小符未激活图案一致）

▪类别 1：小符已激活（small_activated）

▪类别 2：大符已激活（big_activated）

◦5 关键点顺序：点 1~4 为装甲板靶面 4 个角点（逆时针顺序），第 5 点为 R 标中心点。

◦模型可视化：支持在 netron.app 直接上传查看 ONNX 网络结构。

4.实车性能数据：

◦测试硬件：Intel NUC13 (32G RAM)

◦推理引擎：Intel OpenVINO GPU (核显加速)

◦测试场景：自瞄主程序全负载并发运行

◦实测耗时：预处理 + Infer + 后处理单帧全流程仅需 8.5ms（等效 115+ FPS）。

5.实战表现与数据集：

◦数据集：由今年 RobotPilots 战队视觉组从 0 标注的 30k 赛场原始样本中，逐一筛选提炼出 14k 超高质量精选数据训练得到，对强反光与高曝光背景具备极强抗干扰能力；

◦稳定性：实战方案主要使用前两类（未激活、小符已激活），从分区赛到全国赛历经全场次检验，保持了 0 丢帧、0 误识别；

◦注：第三类（大符已激活）由于后期未继续扩充数据集，特定过渡帧可能存在丢帧，建议搭配前两类使用。

三、 快速上手与编译运行

代码基于 C++17、CMake、OpenCV 与 OpenVINO 编写，已开源完整的推理与性能评测工具。

# 1. 克隆代码并进入目录
git clone https://github.com/SZURPVision/RuneDetectionModel.git
cd RuneDetectionModel

# 2. 编译
mkdir build && cd build
cmake ..
make -j$(nproc)

# 3. 导出openvino ir格式
ovc model/model-0624.onnx --output_model model/model-0624.xml

# 4. 运行测试
# 视频流推理与保存
./fivepoints_infer ../model/model-0624.onnx ../video/test_video.avi result.avi --device GPU
./fivepoints_infer ../model/model-0624.xml ../video/test_video.avi result.avi --device GPU

# 性能基准评测模式 (输出 P50/P90/P99 延迟报告)
./fivepoints_infer ../model/model-0624.onnx ../video/test_video.avi --device GPU --benchmark
./fivepoints_infer ../model/model-0624.xml ../video/test_video.avi --device GPU --benchmark
