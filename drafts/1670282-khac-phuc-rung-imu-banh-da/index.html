ARM LiveWatch : VS Code 实时变量监视插件

Nguồn: RoboMaster BBS · Tác giả: Misaka21

Chuyên mục: Điều khiển

前言

在使用 VS Code 进行嵌入式开发时，Cortex-Debug 的 Watch 窗口需要暂停 CPU 才能读取变量值，无法满足 PID 调参、IMU姿态观测等需要持续观察变量变化的场景。ARM LiveWatch 通过 OpenOCD TCL 接口直接访问 MCU 内存，在不中断程序运行的前提下实时刷新变量值，提供与 KeilLive Watch 一致的使用体验。

功能演示

直接在 VS Code 底部面板输入变量名，回车即可实时监视：

•输入 speed_pid → 自动展开结构体，看到 kp、ki、kd 所有成员

•输入 ins_topic.data_->euler → 自动跟踪指针链，实时看欧拉角

•双击值可以直接修改，调 PID 参数不用重新烧录

支持的芯片

所有 OpenOCD 支持的 ARM Cortex-M 芯片：（理论上，不排除有bug）

•ST：STM32F1/F3/F4/F7/H7/G4 等全系列（RM 常用的 F407、H723 都支持）

•GD32、NXP、TI、Nordic 等也支持

环境要求

1.arm-none-eabi-gdb（装了 ARM 工具链就有）

2.OpenOCD 运行中（用 cortex-debug 调试的话已经有了）

3.编译时开 -g 调试信息

安装方法

VS Code 扩展商店搜索 ARM LiveWatch，或者：

ext install Misaka21.arm-livewatch

使用方法

1.启动 OpenOCD 连接开发板，用 cortex-debug 启动调试

2.打开 VS Code 左侧面板 → ARM LiveWatch 标签

3.输入变量名，回车

ELF 文件自动检测，支持 CMake、STM32CubeIDE、PlatformIO、Keil、IAR 等构建环境，不需要手动配置。

典型使用场景

调 PID

输入 speed_pid，展开看 kp/ki/kd/output/integral，双击直接改参数，不用重新编译烧录。

看 IMU 数据

输入 ins_topic，展开看 gyro、accel、euler、quaternion 实时刷新，方便判断 IMU 是否正常。

看电机状态

输入 motor_data，展开看转速、电流、温度、错误码等。

工作原理

•通过 arm-none-eabi-gdb -batch 读取 ELF 中的 DWARF 调试信息，获取变量地址和类型布局（只在添加变量时执行一次）

•通过 OpenOCD TCL 接口 (mdw 命令) 持续读取 MCU SRAM，不影响程序运行

•根据类型信息自动格式化显示（float/int/enum/bool/pointer）
