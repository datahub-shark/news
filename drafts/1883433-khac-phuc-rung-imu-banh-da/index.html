VarScope：一个基于 elf + OpenOCD 的嵌入式变量观察工具

   最近做了一个面向嵌入式调试的小工具。做它的起因是我一直没找到一款足够顺手的软件来配合 DAPLink / CMSIS-DAP 做变量观察。很多时候，我只是想在程序运行时看看 PID、IMU、姿态角、电机反馈、控制量这些全局变量，但又不想额外占用串口，也不想为了临时调试再写一套通信协议。

   所以我尝试用 vibe coding 的方式做了这个工具，目前已经可以比较方便地配合 `elf + OpenOCD + 调试器` 读取 MCU 固件中的全局变量，并进行实时显示、绘图、记录和导出。


它能做什么 ：

VarScope 的核心特点是：不占用串口，直接通过调试器读取变量。

目前支持：

   - 解析带调试信息的 `.elf` 文件。

   - 通过 OpenOCD 连接 DAPLink、CMSIS-DAP、ST-Link 等调试器。

   - 搜索并添加全局变量、结构体成员、数组元素。

   - 单独添加变量或批量添加变量。

   - 实时 Watch 变量值。

   - 实时曲线绘图。

   - 鼠标滚轮缩放图像，左键框选局部区域。

   - 开启“点值”后，可以查看鼠标位置对应时刻附近的变量值。

   - 全局视图中可以观察整体变化趋势，并拖动当前主图观测区域。

   - 支持导出 CSV。

   - 支持存档常用 elf / cfg 路径，方便下次快速切换。


基本使用方式 ：

使用时只需要准备：

   - 带调试信息的 `.elf` 文件。

   - 当前目标板和调试器对应的 OpenOCD `.cfg` 文件。

   - 可用的 OpenOCD。

   - 正常工作的 DAPLink / CMSIS-DAP / ST-Link 等调试器。

打开软件后，选择 `.elf` 和 `.cfg`，点击连接，就可以搜索变量并添加到 Watch / 绘图区域中使用。


适合什么场景 ：

我觉得它比较适合 RoboMaster 或其他嵌入式项目中这类调试需求：

   - 看 PID 输入输出。

   - 看 IMU / 姿态角变化。

   - 看电机反馈。

   - 看控制量变化。

   - 不想占用串口。

   - 不想额外写上位机通信协议。

   - 想快速观察程序运行时的内部变量。
