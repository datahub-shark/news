项目简介

本项目包括EtherCAT 转 CAN 模块的硬件设计和软件设计，以相对较低的成本和难度实现高性能的上位机与底层硬件的沟通。

项目实现了一个具备四路 CAN 接口的 EtherCAT 从站模块。得益于 HPM 平台对 MCAN 的硬件支持与性能优势，本模块在 CAN 通道数量与总线资源上具备更高的工程自由度，该模块在工程机器人场景下具备更强的多电机并行通信能力。

在实际应用中，该模块已在 PnX 战队工程机器人 上完成实装验证并稳定运行整个赛季。当前系统在不降低控制频率的前提下，实现了最高：

  • 挂载 12 个 DM 电机（MIT 控制模式）
  • 挂载 4 个 M3508 电机
  • 所有 CAN 总线控制频率均维持在 1 kHz

在上述高负载条件下，系统未出现明显的通信拥塞、控制降频或稳定性问题，验证了该 EtherCAT 从站模块在多电机、高频控制场景下的工程可行性与稳定性。

论坛文章仅作为项目整体思路与实现效果的概述说明，具体的使用方法、开发流程及软件细节请以 GitHub 仓库内容为准。后续如有功能迭代或小版本更新，也将优先在 GitHub 仓库中进行维护与发布。

实装与验证情况

  • 已完成三种版本的实物打样
  • 在 PnX 战队工程机器人上实装使用整个赛季。
  • 当前未发现明显的通信稳定性问题或EtherCAT 异常或CAN 转发错误等系统级 Bug

软件设计

当前功能

  • EtherCAT 从站
  • EtherCAT ↔ CAN 消息接收转发

软件环境

  • 开发工具链：Segger Embedded Studio
  • 工程结构：基于 HPM 官方 SDK 构建

整个工程文件源码都包含在开源仓库内，可参考笔者的另一篇HPM开发教程使用： https://bbs.robomaster.com/draft/editor/new?t=ARTICLE&draftId=1345989

已知缺点与工程取舍

焊接难度较高，BGA 封装对手工焊接要求高，若正面SMT贴装 BGA，嘉立创贴片费用显著增加，且背面仍需手焊大量 0402 器件（三天消耗两个小朋友）

上位机软件说明

  • 上位机软件由队伍另一位算法组同学负责开发，主要采用了SOEM开源库（Simple Open EtherCAT Master Library）。
  • 上位机控制框架开源：https://bbs.robomaster.com/article/1889188?source=1
