为什么选择滑模控制？

  1. 调参高效：参数数量少、调整范围集中，相较传统控制方案能够减少调试成本。
  2. 跟踪性能良好：在正确建模和整定的前提下，稳态误差与跟踪误差较小，响应直接、延迟感低。2026 赛季，星云 EGA 的步兵、英雄、无人机和哨兵均搭载了滑模算法；其中，哨兵配合自瞄取得局均命中率 Top 1，步兵局均命中率达到 33%。
  3. 公式简洁：相较复杂的前馈—反馈控制结构，本控制器无需对信号进行多级处理，也不需要额外处理普通 PID 中常见的积分饱和等问题。
  4. 迁移性强：控制器针对 Yaw 轴系统建模。对于使用同类 Yaw 电机的不同云台，通常只需微调参数即可完成迁移。

1. 普通滑模控制[1][2]

以下为省略部分工程细节后的核心推导，可据此完成算法移植与适配。

1.1 问题描述

对于云台 Yaw 轴，有：

θ˙=ω\dot{\theta}=\omega

ω˙=α=u+d(t)J\dot{\omega}=\alpha=\frac{u+d(t)}{J}

一个典型的电机位置控制系统可写为：


Jθ¨=u+d(t) J\ddot{\theta}=u+d(t)

其中：

  • JJ：系统等效转动惯量；
  • θ\theta：电机角度；
  • uu：控制输入；
  • d(t)d(t)：摩擦、负载变化等总扰动。

定义位置误差：


e=θ−θde=\theta-\theta_d

其中，θd\theta_d 为目标角度。对误差求导可得：

e˙=θ˙−θ˙d=ω−θ˙d\dot{e}=\dot{\theta}-\dot{\theta}_d =\omega-\dot{\theta}_d

1.2 滑模面设计

设计线性滑模面：

s=e˙+ces=\dot{e}+ce

其中，c>0 为滑模面系数。

1.3 滑模面收敛分析

当系统到达滑模面，即 s=0时：

e˙+ce=0\dot{e}+ce=0

解该微分方程可得：

e(t)=e(0)e−cte(t)=e(0)e^{-ct}

因此，误差将指数收敛至零，收敛速度由c决定。

1.4 控制律推导

选择指数趋近律：

s˙=−ϵsgn⁡(s)−Ks\dot{s}=-\epsilon\operatorname{sgn}(s)-Ks

对滑模面求导：

s˙=e¨+ce˙=u+d(t)J−θ¨d+ce˙\begin{aligned} \dot{s} &=\ddot{e}+c\dot{e} \\ &=\frac{u+d(t)}{J}-\ddot{\theta}_d+c\dot{e} \end{aligned}

忽略不可测扰动 d(t)，可得到控制律：

u=J[θ¨d−ce˙−ϵsgn⁡(s)−Ks]u=J\left[ \ddot{\theta}_d-c\dot{e} -\epsilon\operatorname{sgn}(s)-Ks \right]

实际代码使用饱和函数 sat(s)代替符号函数，以减弱高频抖振：

sat⁡(s)={s,∣s∣≤1 sgn⁡(s),∣s∣>1\operatorname{sat}(s)= \begin{cases} s, & |s|\le 1 \ \operatorname{sgn}(s), & |s|>1 \end{cases}

1.5 稳定性分析

选择李雅普诺夫函数：

V=12s2V=\frac{1}{2}s^2

采用符号函数形式的趋近律时：

V˙=ss˙ =s[−ϵsgn⁡(s)−Ks] =−ϵ∣s∣−Ks2≤0\begin{aligned} \dot{V} &=s\dot{s} \ &=s\left[-\epsilon\operatorname{sgn}(s)-Ks\right] \ &=-\epsilon|s|-Ks^2\le 0 \end{aligned}

因此，系统满足李雅普诺夫稳定性条件，并将逐渐收敛至滑模面。

1.6 普通滑模的局限性

  1. 收敛速度仍可优化：系统在误差较大时收敛较快，但接近平衡点后速度会逐渐降低。
  2. 存在抖振：符号函数会引起高频切换。工程上可使用饱和函数、边界层或高阶滑模等方法进行缓解。




2. 快速终端滑模控制

2.1 滑模面设计

为保证非整数幂在负误差下仍有明确的实数定义，引入幂次符号函数：

sig⁡r(e)=∣e∣rsgn⁡(e)\operatorname{sig}^{r}(e)=|e|^r\operatorname{sgn}(e)

令 r=q/p，设计终端滑模面：

s=e˙+αsig⁡q/p(e)s=\dot{e}+\alpha\operatorname{sig}^{q/p}(e)

其中，α>0\alpha>0。在经典有限时间收敛条件下，p、q 为正奇数，并满足 0<q/p<1。

当 s=0时：

e˙=−αsig⁡q/p(e)\dot{e}=-\alpha\operatorname{sig}^{q/p}(e)

误差幅值随时间变化为：

∣e(t)∣=[∣e(0)∣1−q/p−α(1−qp)t]pp−q|e(t)|= \left[ |e(0)|^{1-q/p} -\alpha\left(1-\frac{q}{p}\right)t \right]^{\frac{p}{p-q}}

相应的有限收敛时间为：

T=pα(p−q)∣e(0)∣1−q/p T=\frac{p}{\alpha(p-q)}|e(0)|^{1-q/p}

2.2 控制律推导

对滑模面求导：

s˙=e¨+αqp∣e∣q/p−1e˙\dot{s} =\ddot{e} +\alpha\frac{q}{p}|e|^{q/p-1}\dot{e}

代入系统方程：

s˙=u+d(t)J−θ¨d+αqp∣e∣q/p−1e˙\dot{s} =\frac{u+d(t)}{J} -\ddot{\theta}_d +\alpha\frac{q}{p}|e|^{q/p-1}\dot{e}

仍采用指数趋近律,忽略不可测扰动 ，得到：

u=J[θ¨d−αqp∣e∣q/p−1e˙−Ks−ϵsgn⁡(s)]u=J\left[ \ddot{\theta}_d -\alpha\frac{q}{p}|e|^{q/p-1}\dot{e} -Ks -\epsilon\operatorname{sgn}(s) \right]


2.3 奇异性处理

当 0<q/p<1 且 e→0e\to 0 时，∣e∣q/p−1|e|^{q/p-1} 会趋于无穷，因此需要处理原点附近的奇异性

if (fabs(error) < 1) {

} else {
    // 终端滑模
