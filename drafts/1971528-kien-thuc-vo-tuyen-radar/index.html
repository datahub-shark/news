使用方法

仓库提供两类资源，可按需取用：

  • Unity 三维场地工程（Project/）：完整仿真场景，需下载 Git LFS 大文件（约 382 MB）
  • 二维雷达地图包（map/）：28×15 m 底图与高度掩膜，不依赖 Unity，可单独使用

1）获取资源

完整克隆（Unity 工程 + 地图包）——两个大模型由 Git LFS 托管，请先安装 Git LFS：

git lfs install
git clone https://github.com/diaofenyuan/RMUC_2027map_unity.git

只取二维地图、不下载 LFS 模型（约十几 MB）：

GIT_LFS_SKIP_SMUDGE=1 git clone --depth 1 https://github.com/diaofenyuan/RMUC_2027map_unity.git

Windows PowerShell：

$env:GIT_LFS_SKIP_SMUDGE = "1"
git clone --depth 1 https://github.com/diaofenyuan/RMUC_2027map_unity.git

地图在 map/ 目录，坐标约定与掩膜语义见 map/README.md。

2）打开 Unity 工程

  • Windows：双击根目录 一键打开场地.bat。脚本会按「环境变量 RMVF_UNITY_EXE → 同目录 unity_path.txt → Unity Hub 标准安装路径」的顺序定位编辑器，并打开 Project/
  • 其他平台：用 Unity Hub 添加 Project/，以 2022.3.62f1 打开，再在 Project 面板双击 Assets/Rmvf/Scenes/U1Field.unity

3）首次打开的预期表现

  • 场地网格约 707 万三角面，首次导入需数分钟，请耐心等待
  • Library/ 目录会增长到数 GB，属正常现象
  • 导入结束后场景会自动载入；若未自动载入，手动打开上述 U1Field.unity 即可

常见问题

  • 编辑器装在非标准路径：在仓库根目录新建 unity_path.txt，第一行写 Unity.exe 的完整路径
  • 模型文件只有 130 字节左右：说明 LFS 对象没拉下来（只是指针文件），执行 git lfs pull；若仍未恢复，确认已安装 Git LFS 后重新执行
  • 不要在资源管理器里双击 .unity 文件：.unity 是 YAML 资产文件，不是可执行程序，必须由 Unity Editor 在某个工程内打开。多版本共存时尤其容易用错版本并触发工程升级
  • 打开后提示升级工程：建议使用 2022.3.62f1；其他 LTS 版本一般也能打开，但会触发工程升级，请自行备份
