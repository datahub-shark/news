1. 简介

   本项目源自北京理工大学 DreamChaser 战队的仿人形七自由度双臂机械臂实车工程。单臂采用球肩、肘关节和球腕组成的 3R-R-3R冗余构型，左右臂复用同一套模板化控制链；当前工程设计中，左臂使用 CAN1、右臂使用 CAN2，每臂控制 J0-J6 七台达妙电机。

   本次开源围绕三个核心问题展开：

输入路由与控制架构：将键鼠、拨杆和模拟通道等输入转换为明确的周期业务意图，使输入设备、业务状态与底层电机控制解耦。

七自由度冗余逆运动学：组合 SEW 臂角解析候选、SEW 一维流形搜索和加权阻尼最小二乘（DLS），兼顾非局部目标的可达性与局部运动连续性。

重力补偿：以势能梯度计算关节重力矩，并将固定安装方向下的模型推广到随腰部姿态和世界参考方向变化的全方向形式。

   本篇文章仅是简介，详细技术细节与公式推导查看开源技术报告。

3. 技术方案

3.1 总体控制链

   系统从输入到执行采用分层设计：

层级 主要职责
Router匹配键鼠、拨杆、通道和组合输入，生成业务意图，不直接执行机械臂动作
FSM / Actions根据当前状态消费 Router 意图，并转换为机械臂目标或状态切换
RoboArmT提供笛卡尔／关节运动、增量控制、复位和禁用等统一接口，管理生命周期与周期调用
ArmMiddleware工作空间与禁区检查、IK/FK、空间映射、轨迹规划、参考坐标系更新和重力前馈编排
ArmDriver电机使能、在线状态、反馈新鲜度、MIT 控制策略及 CAN 指令下发


   Router 采用静态数组、普通函数指针和固定长度数据组织路由表，分发顺序固定为“键鼠 → 拨杆 → 通道 → 组合”。完整工程中的 FSM／Actions 层负责将 RouterOutput 转换为具体动作，从而避免输入设备键位直接侵入运动学和电机驱动。

3.2 七轴模型与左右臂安装

   单臂采用 3R-R-3R 构型：前三个关节构成球肩，中间关节为肘，后三个关节构成球腕。给定六自由度末端位姿后，机械臂仍保留一个冗余自由度，可用于调整肘部姿态、远离关节限位或改善连续运动。

   报告中的主要几何参数如下：上臂长度  158.50 mm，肘部定向偏置 60.00 mm，前臂长度 249.38 mm，末端偏置 92.57 mm，双臂基座间距 220 mm。左右臂分别位于世界坐标系 Y=-110 mm 和 Y=+110 mm。世界目标会先通过各自的安装旋转和平移变换到机械臂本地坐标系，再进入运动学求解。

3.3 SEW 解析逆解、DLS 与 AdaptiveHybrid

   七轴逆解使用 SEW（Shoulder-Elbow-Wrist）臂角描述肘部绕肩—腕轴的冗余运动，并通过几何子问题求解肩、肘和腕的解析分支。理论上三组二值分支最多产生 2 × 2 × 2 = 8 组候选，随后依次执行：

1. 周期等价角与关节限位处理；

2. FK 回代和位姿误差校验；

3. 按相对当前关节状态的加权运动代价选优；

4. 中心臂角不可行时，在 SEW 一维可行流形附近进行有界恢复搜索。

   针对连续小范围目标，系统从真实关节反馈出发执行加权 DLS。DLS 通过阻尼抑制奇异方向的过大关节增量，并结合关节权重、单步限制和信赖域约束保持局部运动连续。

   AdaptiveHybrid 根据末端目标相对当前位姿的变化量，在两条路径之间互斥调度：

                               连续小范围目标  -> 加权 DLS

                               非局部目标      -> SEW 解析候选 + 一维流形 Hybrid

   该调度器不是新的逆解公式，而是对不同求解器适用范围的工程组合。当前 C++ IK 模块采用固定容量数组，不依赖 Eigen、不使用动态内存，可作为独立的 C++20 头文件算法模块集成。

3.4 重力补偿与参考坐标系

   静止和低速阶段，系统根据机械臂势能对关节角的梯度计算重力矩，并将其作为前馈力矩加入电机输出。左右臂安装方向相反，因此固定姿态下两侧的本地竖直参考方向符号不同。

   当双臂安装在可俯仰平台上时，重力方向在机械臂本地坐标系中会随腰部 Pitch 和世界参考坐标系变化。方案先将世界竖直方向依次变换到双臂中间坐标系和左右臂本地坐标系，再统一计算各关节重力矩，从而把单方向补偿推广为全方向补偿。

3.5 安全约束与状态管理

   从目标输入到电机下发之间，控制链设置了多层检查：

1.连续有效的 Pitch／IMU 快照与初始化稳定门槛；

2.七路电机在线状态和反馈新鲜度检查；

3.笛卡尔工作空间限制与应用禁区；

4.关节限位、增量限制和输出检查；

5.IK 失败、非法反馈、越限和禁区等错误诊断；

6.软复位、经验分段硬复位和请求式延时禁用；

7.中间层运动状态与驱动层到位状态的独立维护。

4.3 开源范围说明

   Double7RArm 是从完整实车工程中整理的重要核心代码，不是可直接编译、烧录的完整固件发行包；仓库未包含全部板级工程、构建脚本、全局实例、硬件参数和外部设备依赖。

   仓库中只有 7Dof_IK 具备完整依赖链，可独立使用 C++20 编译器集成；Arm 与 Router 仍依赖完整工程中的中间层、单位库、操作系统、DR16、达妙驱动和业务状态代码。

   Double7RArmSim 是运动学计算与可视化代码，不是动力学或物理仿真器；它不包含实车控制、双臂耦合优化、碰撞检测或在线避障。

5.4 当前边界

1.DLS 属于局部方法，沿闭合笛卡尔路径持续运动时，个别关节可能产生累积漂移并进入限位。

2.解析分支切换可能破坏关节轨迹连续性；当前尚未完成严格的中长距离 point-to-point 连续轨迹规划。

3.软复位和硬复位使用经验分段路径，不等同于完整碰撞规划或在线避障。
