ros2-web-desktop：浏览器远程开发查看 RViz2 / rqt，无需 X11 转发

Nguồn: RoboMaster BBS · Tác giả: 通讯信息 email:gavinxleele@gmail.com

Chuyên mục: AI & ROS

大家好，我最近把一个调 ROS 2 图形界面的小工具整理开源了：ros2-web-desktop。

GitHub：https://github.com/lizuju/ros2-web-desktop

它解决的问题很具体：远程 Ubuntu / ROS 2 设备上跑 RViz2、rqt、rqt_graph、rqt_image_view，本地 Mac / Windows / Linux 只用浏览器和 SSH 查看并终端开发，不用 X11 转发，也不用本地安装 ROS、RViz、VNC 客户端。

核心特点

  • 本地轻量：浏览器 + SSH 即可。
  • 保留原生 RViz2 / rqt 调试习惯，不用迁移配置。
  • 默认 SSH 隧道，不直接暴露 noVNC 服务。

对比
Foxglove 更适合数据面板和录包回放；ros2-web-desktop 更适合直接打开原生 RViz2 / rqt。

ToDesk / NoMachine 更像完整远程桌面；这个项目更偏 ROS 2 开发调试，本地不用客户端，也不需要账号体系。

RoboMaster 工作流

写自瞄和导航算法时，用 VS Code Remote SSH 改代码和跑 launch，再用这个工具看和操作相机图像、检测结果、tf 和调试 marker。

也可以在浏览器里操作 map、LaserScan、PointCloud、RobotModel、TF、costmap 和规划路径，终端里直接跑 ros2 topic list、rqt_graph 排查。

安装、启动、自检、断连命令都在 README 和 Releases 里。
