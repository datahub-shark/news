简介


依据上赛季研发思路继续改进设计的双向能量传输的无线充电器控制系统，已经在26赛季国赛成功通过检录并上场使用


本项目覆盖：

1.四开关 Buck-Boost 前级，宽输入范围下输出稳定 V_LINK；

2.LCC 全桥后级，调频调压 + 移相调功 + PLL 谐振频率跟踪；

3.电感电流直接作为数字控制输入的电流模式数；

4.单输入调制器——一个标量编排四开关，无缝双向功率流；

5.双 ADC 独立触发采样架构——两个控制域在采样源头物理隔离；

6.面向无线充电场景的完整保护与故障管理体系。


本工程采用 前级四开关 Buck-Boost + 后级全桥 LCC 谐振 的级联架构，把"母线调节"与"无线传输"解耦到两个独立控制域：

V_IN ──→ [四开关 Buck-Boost] ──→ V_LINK ──→ [LCC 全桥谐振] ──→ 线圈 ──→ 接收端
             PWM1 (200kHz)                    PWM0 (114.514kHz)
级职责
Buck-Boost 前级宽输入电压适应，把 V_IN 调节为稳定可调的中间母线 V_LINK，承担功率/电压/电流闭环
LCC 后级谐振无线传输，通过调频 + 移相控制线圈电流与传输功率，PLL 跟踪谐振点

前级让输入电压不再成为约束，后级让谐振传输不受母线波动影响，两级各司其职、独立闭环。

双 ADC 独立触发采样架构

两个控制域分别由各自的 PWM 实例通过 TRGM 触发各自的 ADC，从采样源头物理隔离：

PWM0_CH8  (148kHz, CMP8 ) ──TRGM──→ PTRGI0A (trig_ch=0) ──→ ADC0  （LCC 控制域）
PWM1_CH10 (200kHz, CMP10) ──TRGM──→ PTRGI1A (trig_ch=3) ──→ ADC1  （Buck-Boost 控制域）
ADC 实例触发源PMT 采样通道（实际配置）服务对象
ADC0PWM0 (148kHz, CMP8)I_LF, I_COIL, I_INLCC 控制 + 输入电流监测
ADC1PWM1 (200kHz, CMP10)I_L, V_LINK, V_INBuck-Boost 控制

每个 ADC 实例的 PMT 队列为 4 通道，位置 0 放 dummy 通道（ch15）以规避 HPM5361 ADC16 PMT 首次转换结果异常，有效通道 3 个。采样均在载波中心触发（position_ratio = 0.5），避开开关噪声点。详见 §3.7 与 control_loop_design.md §2.4。

通道映射以 app_adc.c 的 PMT 队列实际配置为准（运行时生效）。工程内 adc_map 表与 README.md、control_loop_design.md 中的通道表存在过时表述，与本表不一致时以本表为准。

两级控制级联

Buck-Boost 控制域（ADC1 + GPTMR1，PWM1 执行）:
  功率外环 (25kHz): PI(p_target, p_in) → signed v_out_target_v
      │
      ▼
  电压外环 (50kHz): PI(v_out_target, v_link) + 负载电流前馈 → current_ref
      │  （CC 环竞争：PI(i_link_target, i_in_calc) → current_ref 的保守值）
      ▼
  电感电流内环 (100kHz PI, 200kHz 采样): PI(current_ref, i_l) → V_L_cmd
      │
      ▼
  VIN/VLINK 前馈 → generalized_duty → 单输入调制器 → DA, DB

LCC 控制域（ADC0 + PWM0，PWM0 执行）:
  线圈电流内环 (148kHz): PID(i_coil_target, i_coil) → 频率 + 移相角
  PLL 锁频环: 跟踪谐振频率

关键设计决策

Buck-Boost + LCC 两级级联

无线充电系统若只用单级全桥直接驱动谐振网络，会面临两个耦合在一起的难题：

  1. 输入电压适应性：V_IN 波动会直接改变谐振网络的激励幅度，进而改变线圈电流与传输功率，控制器必须同时应付"母线波动"与"耦合变化"两重扰动；
  2. 调节手段单一：全桥只能靠占空比/移相调节输出，既要稳压又要限流，调节维度不足。

两级级联把问题拆开：

  • Buck-Boost 前级专职"母线调节"——把波动的 V_IN 变为稳定可调的 V_LINK，其闭环与无线传输完全无关；
  • LCC 后级专职"谐振传输"——在一个稳定的母线上做调频 + 移相，只处理耦合与谐振点变化。

两级的采样、触发、闭环各自独立，互不干扰，也便于分模块调试与复用。

LCC 后级"调频 + 移相"两种手段

LCC补偿网络在谐振点附近具有良好的恒流特性与软开关条件，但实际谐振点会随线圈耦合、气隙、器件容差漂移。仅靠移相（调功）无法补偿频率漂移，仅靠调频（调压）调节范围有限。

本工程同时提供两种调节维度：

  • 调频：改变 PWM0 开关频率，偏离/逼近谐振点以改变谐振网络增益，实现宽范围电压调节，并配合 PLL 把频率锁定到谐振点附近；
  • 移相：调节全桥两半桥之间的相位差，直接控制输出功率与线圈电流。

两者叠加，使 LCC 后级既能跟踪谐振点，又能精细调节传输功率。

Buck-Boost 的 VIN/VLINK 前馈

Buck-Boost 的占空比到电感电流的增益随 VIN、V_LINK 变化。若不加前馈，PI 参数只能针对某一工作点整定，母线电压大范围变化时环路增益漂移，动态性能下降。

前馈把"给定平均电感电压 → 占空比"的映射显式化：

V_L = DA × VIN − DB × VLINK = Dmax × [(VIN + VLINK) × g − VLINK]

g = (V_L_cmd / Dmax + VLINK) / (VIN + VLINK)

PI 只需补偿剩余误差，从而在宽输入电压范围下保持一致的环路特性。前馈分母设 VIN + VLINK < 1V 时拒绝计算（BUCKBOOST_BUS_SUM_MIN_V），并做 NaN/Inf 防御，保证鲁棒性。

双 ADC 独立触发架构——两个控制域的采样物理隔离

两个控制域各自独占一个 ADC 实例，由各自的 PWM 通过 TRGM 独立触发：

PWM0_CH8  (148kHz) ──TRGM──→ PTRGI0A (trig_ch=0) ──→ ADC0  → I_COIL / I_LF / I_IN
PWM1_CH10 (200kHz) ──TRGM──→ PTRGI1A (trig_ch=3) ──→ ADC1  → I_L / V_LINK / V_IN
  • ADC0 只响应 trig_ch=0（PWM0），服务 LCC 控制域；
  • ADC1 只响应 trig_ch=3（PWM1），服务 Buck-Boost 控制域；
  • 每个 ADC 独立 DMA（pmt_dma0[48] / pmt_dma1[48]），独立 ISR，零共享竞争。

PMT 队列隔离通过 adc16_enable_pmt_queue / adc16_disable_pmt_queue 实现（drv_adc.c），PTRGI 输入广播到两个 ADC 后由各自队列开关过滤。

  • 采样时刻各归其位：每个控制域的采样都精确落在各自载波中心（0.5×reload），从源头规避开关噪声；
  • 触发完全解耦：LCC 的 148kHz 与 Buck-Boost 的 200kHz 两套采样节奏互不干扰，各自闭环带宽独立设计；
  • 中断优先级分层：ADC0 PMT（优先级 1）、ADC1 PMT（优先级 2）各自独立抢占，控制域之间无共享瓶颈。

平台选型：HPM5361

无线充电这类"高开关频率（148~200kHz）+ 多层闭环 + 逐周期电流控制"的数字电源，对 MCU 的算力、采样精度与触发时序确定性要求极高。本项目选用 HPMicro HPM5361（RISC-V，480MHz，双核）。

维度说明
内核RISC-V（RV32-IMAFDCPB），双核 480MHz
浮点双精度 FPU + DSP/SIMD
本地存储器128KB ILM + 128KB DLM（零等待），热路径部署
ADC2× 16 位 ADC16，原生高精度，PMT 模式
PWM2× HRPWM，28 位扩展计数器，3.0ns 调制精度
触发互联TRGM 互联管理器 + ADC PMT（PWM 匹配触发）
通信CAN 2.0B（MCAN）

① 算力：双控制域全软件闭环

200kHz 电流环 + 148kHz 线圈电流环 + 50kHz 电压环 + 25kHz 功率环，全软件闭环。480MHz 双核 + 双精度 FPU 使逐周期完成"采样 → 滤波 → PI → 前馈 → 调制"整条链路成为可能，无需把控制算法下放硬件加速器或降低开关频率。

② 确定性本地存储：ILM/DLM 部署热路径

中断服务程序的执行时间必须确定，否则采样到 PWM 更新之间的抖动会引入控制误差。128KB ILM（指令）+ 128KB DLM（数据）零等待访问，是数字电源 ISR 的理想居所。本项目把热路径函数标 ATTR_RAMFUNC（__attribute__((section(".fast")))），控制器状态置于快速 RAM。

③ 原生 16 位 ADC：无需过采样的高精度反馈

电流采样链路直接受益于原生 16 位 ADC 的高分辨率，无需硬件过采样即可获得高精度反馈，避免了过采样带来的等效采样率损失或延迟。这对逐周期电流控制尤为关键。

④ 双 ADC + TRGM/PMT 硬件触发链

两个独立 ADC 实例 + TRGM 互联 + PMT 抢占式触发，正是 §3.7 双 ADC 独立触发架构的硬件基础——HPM5361 原生提供两路 ADC 与灵活的 PWM→ADC 触发路由，无需额外外设拼凑。
