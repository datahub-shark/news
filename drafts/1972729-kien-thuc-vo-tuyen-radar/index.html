所以无线信号是什么

一个简单的正弦信号，可以用幅度、频率和初始相位描述。真实接收信号还包含调制、噪声、干扰和信道影响。
[Hz] - 正弦信号的频率

[dB] - 噪音的幅度

IEEE对“无线电”的定义就是“无线发送或接收电磁辐射以传递信息的技术”。因此，SDR处理的对象，正是天线所捕获或即将发射的电磁波信号。

从最简化的角度看，一个SDR接收机可以被理解为：

天线（将电磁波转换为电压）→ 模数转换器（ADC，对电压进行高速采样）

这个定义点明了电磁波是SDR系统的物理输入：从电磁波到比特，再回到电磁波。

无线电是怎么工作的

接收路径：

  1. 天线捕获空间中的电磁波，并将其转换为微弱的模拟电信号（电压）。
  2. 模拟前端（可选）对信号进行放大、滤波，并可能通过混频将其下变频到中频（IF）。
  3. ADC（模数转换器）将模拟信号数字化，变成一串离散的数字样本。
  4. 数字处理单元（处理器/FPGA）运行软件，对这些数字样本进行解调、解码等处理，最终恢复出原始信息（比特流）。

发射路径：

  1. 软件生成承载信息的数字信号。
  2. DAC（数模转换器）将数字信号转换为模拟信号。
  3. 射频前端将模拟信号上变频、放大。
  4. 天线将电信号转换回电磁波辐射出去。

吉布斯现象

看红线在跨越蓝色方波的台阶时。当蓝线突然往上跳时，红线冲上去后并没有平齐，而是超出了蓝线的最高点，然后才落下来；当蓝线突然往下跳时，红线也会跌破蓝线的最低点，然后再反弹回来。

这就是振铃（Ringing）：

在跳变发生后的一小段距离内，红线就像弹簧一样，在水平线附近来回抖动几下，才慢慢趋于平稳。

吉布斯现象的一个极其重要的特征（很反直觉）：

你可能以为，如果我把叠加的正弦波数量（n）增加到一万、一百万项，这个“冒尖”的起伏应该会消失吧？不会的。

随着叠加的项数越来越多，那个“尖”的宽度会变得非常非常窄（越来越紧贴跳变边缘），但尖的最高点超出方波幅度的比例（大约9%）几乎保持不变。它永远无法完美重合直角。

为什么会产生吉布斯现象？

因为傅里叶级数是用无穷多个平滑的正弦波去叠加逼近一个“有棱角”的方波。

  • 在这张图里，为了能画出来，我们只取了有限个正弦波（比如前几项或前十几项）。
  • 这意味着我们突然“一刀切”切掉了所有高频成分。这在数学上叫做“带限（Band-limited）”。
  • 频域突然截断，导致时域上产生了“滤波器拖尾”，在发生剧烈变化的地方（边沿），波形因为“反应不过来”而产生惯性过冲。

吉布斯现象可以消除吗？

这正是现实世界中的物理限制：任何真实的无线电设备（包括 SDR 的 ADC/DAC、天线、滤波器）都不可能拥有无限大的带宽。

你的系统只要存在一个频率上限（比如只能处理到 100MHz），在发射或接收那些带有突然跳变的数字方波信号时，物理上必然会产生这种过冲和振铃。

但实际上可以避开，如果这种尖峰过冲太大，在电路里可能会导致数字信号的误判（0 变成 1），或者烧毁功率放大器。

所以工程师在设计系统时，经常要加入“脉冲成型”（比如升余弦滤波器），把原来的方波边缘弄平滑，提前避开吉布斯现象。

如何将信号分解成正弦波

正弦波（sine wave, 或称为 sinusoid）

其存在三个属性：

  1. 幅度（Amplitude）
  2. 频率（Frequency）
  3. 相位（Phase）

幅度 表示波的“强度”，而 频率 则是指每秒钟时长内完整波形的数量。 相位 用于表示正弦波在时间上的移动，范围从 0 到 360 度 (或 0 到 ) ， 但它必须相对于某物才有意义，比如两个频率相同的信号可能会相差 30 度的相位。

“信号”的本质 —— 一个函数

通常是在“时间”这个轴（即 x 轴）上来表示的。 另外一个容易记忆的特性是 周期 ，它是 频率 的倒数。正弦波的 周期 是波完成一个循环所需的时间，单位是秒。 因此，频率的单位是 1/秒，或者赫兹（Hz）。

当我们将信号分解为一系列的正弦波时，每一个波都会有一定的 幅度 、相位 和 频率 。 每个正弦波的 幅度 将告诉我们原始信号中该 频率 的强度。先不用过多担心 相位 ， 其实你只需意识到  和  之间唯一的区别就是一个相位移动（时间位移）。

最后，为什么“永远无法完美”？

就像图里展示的那样，无论你加多少正弦波（n增加到无穷大），那个过冲（9%的尖尖）永远都在。

因为完美的瞬间跳变（无限快的斜率），需要无限宽的频率（无限多的高频正弦波）。现实中的 SDR 不可能有无限的带宽，所以物理世界里，完美的方波是不存在的。

所以：无线电通信的本质，就是用系统最擅长发出的、平滑纯粹的正弦波（coser），去拼命模仿那些带有棱角、包含复杂信息的基带波形（原角色）。虽然因为带宽限制总会有一点点“穿帮（吉布斯现象）”，但只要穿帮得足够小，接收端依然能认出它传达的信息。

时间 - 频率性质

我们之前检查了信号在时域和频率域中的表现形式的例子。现在，我们将涵盖五个重要的“傅里叶性质”。

注意！ 这些性质告诉了一个什么样的事情呢：

如果我们对时域信号做 ____ ，那么 ____ 将发生在频域信号上。

1. 线性性质

如果我们在时间上加总两个信号，那么在频域中对应的也会是两个频域信号的加和。这也告诉我们：

如果我们将其中一个信号乘以一个缩放因子，频域中的表示也会相同比例地缩放。这个特性的实用性会在我们加总多个信号时变得更加明显。

所以通俗点讲：

  • 时域相加 = 频域相加：你在时间轴上把两个波形叠在一起，就等于把它们各自的频谱图叠在一起。
  • 乘个系数 = 等比例放大：你把时域信号的音量调大两倍，频域里的能量也刚好高两倍。

因为自然界是一个超级强的加法器，你在空气中说话，同时旁边有个人在敲鼓。这两路声波（电磁波）在空气中相遇，它们就是简单地相加。你的 SDR 天线接收到的信号，其实就是无数个不同频率、不同强度的正弦波（来自各个基站、WiFi、蓝牙、甚至宇宙背景辐射）线性叠加在一起的总和。

2. 频移性质

x(t) 左边的项我们称之为**“复数正弦波” **or "复数指数"。目前我们所需要知道的是，它本质上其实就是一个频率为f0的正弦波。这个属性告诉我们：

如果我们将一个信号 x(t) 与一个正弦波相乘， 那么在频率域我们得到的是 X(f) ，只是频率偏移了一定的 f0 。

频移的本质，就是把信号的频率中心，从一个位置“搬”到另一个位置。 时域“乘”正弦，频域“移”位置：你把原来的信号，和这个不断旋转的正弦波乘在一起，就相当于给原信号的频谱施加了一个力，把它整体在频率轴上向左或向右平移了 f0 的距离。

频偏操作对于DSP应用来说是非常重要的，因为我们出于多种原因需要将信号在频率上进行上移或下移。这个性质告诉我们如何通过乘以一个正弦波去实现频偏操作。数学上来说，复数正弦波就是欧拉公式，在复平面上它是一个一直在旋转的指针。

  2. 傅里叶级数的基石：正因为有线性性质，我们才能把复杂的方波，拆解成基波 + 3次谐波 + 5次谐波去单独研究，然后再加起来。

3. 时域缩放性质

即时频对偶性（Time-Frequency Duality）

在方程的左边，我们可以看到在时域中对我们的信号 x(t) 进行了缩放。 这里有一个信号在时间上缩放的例子，我们看看频域上发生了什么变化：

时域上的缩放本质上是在 x 轴上缩小或扩展信号。这一属性告诉我们：

在时域上的缩放会导致在频域上的逆向缩放。

例如，当我们更快地传输比特流时，结果是使用了更大的带宽。这一属性有助于解释为什么更高数据率的信号会占用更多的带宽/频谱资源。 时域越窄，频域越宽；时域越宽，频域越窄。

想象你在听一段录音，你把播放速度调成了 2倍速（a=2a=2，时域压缩）。

  • 声音在时间轴上缩短了一半。
  • 你的耳朵听到什么？声音变得尖锐、音调变高了。音调变高，在物理上就意味着频率翻倍了。

反过来，如果你用 0.5倍速（a=0.5a=0.5，时域拉伸） 播放，声音会变得低沉、缓慢，因为频率被压缩变低了。

为什么重要？（SDR 的核心原理）
  1. 上变频与下变频（混频）：
    • 你要发射信号，基带信号（比如你录的音频）频率很低，只有几千赫兹，天线根本发不出去（天线尺寸得几千米长）。你必须把它的频谱“搬家”到 2.4GHz 附近（WiFi频段），天线才能高效辐射。这叫上变频。
    • 你在手机上接收信号，收到的是 2.4GHz 的极高频信号，但你的芯片（ADC）处理不了这么快的信号，必须把它“搬家”回到 0Hz 附近（基带）去处理。这叫下变频。
  2. 频分复用（FDM）：为什么那么多人同时用手机，互不干扰？因为运营商给每个人的信号分配了不同的频率（比如你占用 1.8GHz 搬家后的位置，他占用 1.9GHz 搬家后的位置）。大家互不干扰，这就是频移的功劳。

公式里还有一个参数 1/|a| ，它代表的是幅度（能量）的变化。当你把时间压缩时，信号被挤在更短的时间里，所以它的瞬时振幅通常会变大（面积不变原则），但在无线电通信中，我们最关心的是“带宽”（频率的展宽程度），幅度变高变低可以通过放大器（PA）来调整，所以我们通常忽略这个幅度因子，只看频率轴上的宽度变化。

所以如果你想让你的基站传输速度翻倍（时域压缩一半），你就必须占用两倍的频宽（频域拓宽一倍）。

但是有一个原理与工程上的区别

数学上的频移，是乘以“复正弦波”（只往一个方向搬）。但在现实物理电路中，我们没法直接产生复数信号，我们只能乘以实数正弦波 cos⁡(2πf0t)cos(2πf0t)。

根据积化和差公式：信号 ×cos⁡(2πf0t)×cos(2πf0t) = 一半向左搬，一半向右搬。

所以在频域图上，你如果用真实的物理电路做乘法，你会看到频谱同时向左和向右平移了一份（这被称为双边带调制）。这就是为什么你看通信原理的图，频谱往往是关于中心对称的。

为什么高数据率需要大带宽？
  • 低速传输：假设每个比特占用的时间很长（比如 1 毫秒），波形很宽。这就相当于“时域很宽”。在频域里，它需要的频率范围就很窄（不需要太陡峭的边缘，低频正弦波就能cos）。
  • 高速传输：如果我们把传输速度提高 100 倍，每个比特占用的时间就缩短到了 10 微秒。这就相当于在时域上把信号“压缩”了（a 变大了）。
  • 频率上的代价：为了cosplay出这种“极短时间”内产生的剧烈跳变（方波边缘），你必须引入极其高频的正弦波来拼凑。因为时间越短，变化越剧烈，需要的“高频谐波”就越多。
  • 结果就是：频域图上的波形被“拉宽”了。数据率越快，占用的频谱带宽就越大。

4. 时域卷积性质 and 频域卷积性质

因为我们考察的是在时域中将 x(t) 与 y(t) 进行卷积后的性质，所以称之为卷积性质。

所以什么是卷积呢

我会在后面讨论滤波器的时候细致地说这个是个啥，所以这里姑且将它想象成一种互相关运算


积，就是一个冲激的猛烈程度（幅度）和 系统对它的保留/衰减比例（权重）相乘，算的是现在这一时刻这个冲激对系统的影响；

卷，就是越早的冲激要对应越晚的影响，越晚的冲激对系统的影响越大，所以冲激发生的顺序和单次冲激影响的衰减的对应关系其实是“翻转”过来的，从当前时刻，时光倒流去看一个已经衰减至现在的冲激，这个冲激是在增大的，这就是翻转的由来。最后在当前时间上把所有冲激此时对系统的影响相加，得到此时系统内的影响总和。

加法：就像你把两杯水倒进同一个杯子里。水还是那些水，只是混合了。在频域图上，就是把两根谱线画在一起。
卷积：就像把面粉（信号）和酵母（系统冲激响应）揉在一起，烤成了面包。信号在卷积之后，它的形状、持续时间、频域结构发生了根本性的质变。这就是“滤波”：原本混杂着高频和低频的信号，经过“系统（滤波器）”的揉捏，变成了一个全新的、只留下特定频率的新波形。

时域卷积 = 频域相乘

(注：⊛ 代表卷积，× 代表相乘)

这在物理上意味着：你在时域里做极度复杂的卷积运算，等价于在频域里做极度简单的乘法。

举个例子

假设你正在用 SDR 听收音机，你的天线收到了：

  1. 你想要的电台（频率 100MHz）
  2. 隔壁老王的干扰信号（频率 105MHz）

你想把老王的声音掐掉，只留电台的声音。怎么办？

  • 频域视角（最简单直接）：你画一个只允许 100MHz 通过的“矩形框”（这就是掩码/Mask）。把这个框和收到的信号频谱相乘。结果就是：100MHz 的留下了，105MHz 的乘以 0 变成了 0，干扰被完美抹除。
  • 时域视角（现实物理世界）：你不可能直接跑进频域去画框，你只能在时域里处理。怎么弄？把收到的信号，和那个“矩形框”的时域表现形式（这就是滤波器的冲激响应，或者说“印章”）进行卷积。
为什么“不可能直接跑进频域去画框”？

假设你收到了一个混合信号（你要的 100MHz 电台 + 隔壁老王的 105MHz 干扰）。

如果是在数学作业里，你确实可以画个频域图，拿个橡皮擦把 105MHz 擦掉，留下 100MHz，然后再逆傅里叶变换变回来。

但在物理现实中，你的电路和软件没有“上帝视角”去直接擦除某个频率。

真实世界的硬件（比如天线、电阻、电容、放大器、ADC）和软件（代码里的加减乘除），全都只能针对“此刻的时间点”进行操作。时间一点点流逝，你只能一点点处理数据。你没法让时间暂停，跳到“频率轴”上去切割。

这条性质极其重要

因为计算卷积非常极其慢！如果信号有 100 万个采样点，直接做时域卷积，计算量是天文数字。但是，如果把它变到频域（用快速傅里叶变换 FFT），只需要做 100 万次乘法，这就是现代 5G、WiFi 为什么能跑那么快的原因之一，就是我们都在频域里做乘法。

频域卷积 = 时域相乘（反向操作）

这个性质平时不太常用。但是如果你搞无线电（SDR、WiFi、5G），这个反向性质是我们的命根子，“频移（调制）”和“欧拉公式”，就属于它的一种体现：

  • 我们之前说，时域里把信号乘以一个正弦波

在频域里就会发生“平移”。

  • 时域相乘： 比如你把基带信号 x(t)x(t) 乘以一个高频载波 cos⁡(2πfct)cos(2πfct)。

  • 频域卷积： 根据性质，这等价于把基带信号的频谱，和载波的频谱（两根冲激线）做卷积。
  • 如果你用这条性质解释：信号×正弦波信号×正弦波，在频域里就是 原信号频谱⊛正弦波的频谱原信号频谱⊛正弦波的频谱。而一个纯粹正弦波的频谱是一个 “δ冲激（一根线）”。
  • 任何东西和 δ冲激做卷积，结果就只是把原信号平移到那个冲激的位置，这就是频移的底层数学逻辑。

工程师设计的 IQ 调制器（复混频器），其实就是用数字代码在时域里做乘法，从而在频域里完成极其精密的频谱切割和搬运。

这个性质为什么这么重要

考虑这样一种情况：你有一个想要接收的信号，而旁边就有一个干扰信号。

掩码（masking）在编程中的应用非常广泛，我们在这里就利用一下这个概念。如果我们能创建下面的掩码，并将其与上方的信号相乘，以便屏蔽我们不想要的信号。

我们通常在时域进行 DSP 操作，那么我们利用时域卷积性质来看看如何在频域进行这种掩码。假设 x(t) 是我们接收到的信号。 Y(f) 是我们想要在频域应用的掩码，y(t) 是我们掩膜的时域表示， 如果我们将它与 x(t) 进行卷积，我们就可以“过滤掉”我们不想要的信号。

所以...

“正弦波是物理世界的积木，傅里叶变换是图纸，而五大性质是拼装说明书。”
  • 线性：告诉你积木可以随便加。
  • 缩放：告诉你积木的大小与占用空间成反比。
  • 频移：告诉你如何把不同颜色的积木搬到不同的楼层（频段）。
  • 时域卷积：告诉你现实中怎么用带惯性/余波的物理设备去筛出想要的积木（滤波）。
  • 频域卷积：告诉你如何把基带信号“附魔”（调制）到高频载波上发射出去。
你在时域做加法，频域也就做加法。 你在时域挤压时间，频域就会拉开频率（缩放）。 你在时域乘正弦波，频域就平移（频移）。 你在时域做卷积（滤镜），频域就做乘法。 你在频域做卷积（涂抹），时域就做乘法（调制）。
  1. 线性（相加）：物理世界的大杂烩。所有的信号（你要的、干扰的）在空气中简单加在一起，互不干扰。
  2. 时频缩放：鱼与熊掌不可兼得。你发得快（时域挤），就占频带宽（频域拉伸）。
  3. 频移（时域乘正弦）：坐电梯。把信号搬到更高的楼层（频率），或者降下来。
  4. 时域卷积（物理滤波）：拿着印章（冲激响应），在时间轴上滑过去。过去的历史余波叠加，把不要的信号“抹平”。
  5. 频域卷积（通信调制）：数学魔法。把信号的频谱像和面一样，擀到不同的频率位置上。
