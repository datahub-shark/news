SharkClient-基于Tauri+Rust+Vue的RM自定义客户端方案

SharkClient 是一个为 RoboMaster 机器人比赛设计的浏览器自定义客户端，提供：

  • 🎥 实时视频流: 基于 WebSocket/共享内存的 的低延迟图传
  • 🤖 AI 目标检测: 集成装甲板和车辆实时监测和血条绘制（内置Py脚本）
  • 🎮 战术 HUD: 准星、弹道辅助（迫真）、状态显示
  • ⚙️ 机器人控制: IP 配置、串口通信、参数设置
  • 📊 数据遥测: 实时数据监控和日志记录
  • 👊 自定义UI配置：允许操作手自由配置任意主界面元素，可以DIY你自己的数据看板
对比旧版Electron方案的旧版客户端，最终产物由230M+减少到30M左右，同时降低了资源占用

核心功能

1.主界面看板

  • UDP与MQTT协议（支持本地broker）实现
  • 实时目标检测覆盖层
  • 带颜色的模块状态徽章 (相机/检测/通信)
  • 检测服务状态实时显示
  • 自定义准星和瞄准辅助
  • 准星预设保存/加载/删除
  • 枪口热量可视化

2.AI检测

🔍 AI 目标检测

  • 服务器端: Python Pipe内存共享 + ONNX Runtime (支持 TensorRT/CUDA/DirectML/CPU)
  • 客户端绘制: Canvas 高性能渲染
  • 智能颜色: 自动红蓝队伍识别
  • 实时性: 60+ FPS 检测频率 (Named Pipe 模式，Tensorrt)
  • 车辆跟踪血条 HUD - 十字准心 + 虚线连接 + 血量指示条
  • 车辆编号自动识别（依赖 ROI 内最高置信度装甲板）
  • 跨组件状态同步 - Settings 启动服务器后 Dashboard 实时更新状态

环境要求

  • Node.js >= 18.x
  • Python >= 3.9 (用于目标检测)
  • 操作系统: Windows / Linux
