本项目基于 MATLAB 开发，用于快速评估四轮舵轮底盘在不同机器人参数、轮胎参数、电机参数和运动工况下的性能表现。它面向早期设计阶段，帮助使用者快速判断底盘方案是否合理，并辅助机械、电控和算法团队进行方案讨论。

软件及版本：MATLAB(25.2.0.3042426 (R2025b) Update 1)

1. 项目目的

本项目主要用于回答以下问题：

  • 底盘理论最大直线速度是多少？
  • 底盘理论最大自转速度是多少？
  • 当前工况下四个轮子的轮速和舵角分别是多少？
  • 驱动电机和转向电机需要多大扭矩？
  • 巡航额定扭矩和当前峰值扭矩差多少？
  • 哪个轮子的法向载荷最大？
  • 哪个轮子最接近打滑？
  • 轮胎包胶是否接近压到底？
  • 改变质量、轴距、轮径、包胶厚度、摩擦系数、减速比后，性能会如何变化？

本工具适合用于：

  • 四轮舵轮底盘早期方案设计；
  • RoboMaster / 移动机器人底盘参数对比；
  • 电机和传动系统初步选型；
  • 轮胎包胶厚度、硬度、宽度影响分析；
  • 机械组、电控组、算法组之间的设计沟通；
  • 工程教学与可视化展示。

本工具当前不是高保真车辆动力学仿真器，也不应作为最终电机选型或实车安全裕度认证的唯一依据。

2. 项目工作原理

本项目的计算流程如下：

机器人参数 + 测试工况
        ↓
理论性能边界计算
        ↓
舵轮运动学解算
        ↓
舵轮动力学估算
        ↓
统一工况评估
        ↓
命令行报告 / Dashboard 可视化

更具体地说：

  1. 读取参数 从 Config_Params.m 和 Swerve_Get_Preset.m 中读取机器人质量、轴距、轮距、轮径、包胶厚度、电机转速、减速比、摩擦系数等参数。
  2. 计算理论边界 Swerve_Performance_Limits.m 根据轮径、电机最高转速和减速比计算理论最大直线速度、最大自转速度和最大转向角速度。
  3. 运动学解算 Swerve_Kinematics_Solver.m 将底盘速度指令：
   前向速度 vx
   右向速度 vy
   角速度 omega_z

转换为四个舵轮的：

   驱动速度
   目标舵角
   转向角速度
  1. 动力学估算  
    Swerve_Dynamics_Core.m 根据当前加速度工况计算：
    • 四轮法向载荷；
    • 载荷转移；
    • 驱动扭矩；
    • 转向扭矩；
    • 抓地利用率；
    • 打滑风险；
    • 轮胎包胶下压形变；
    • 包胶触底风险。
  2. 统一评估 Swerve_Evaluate_Case.m 将运动学、动力学和性能边界统一封装为一个完整工况结果。
  3. 结果展示 main.m 输出命令行报告。 Swerve_UI_Dashboard.m 提供图形化界面，用于修改参数、查看指标、图表和逐轮结果。

3. 坐标系与轮序约定

本项目统一采用机器人本体系坐标：

X 轴：机器人前方为正
Y 轴：机器人右侧为正
Z 轴：机器人上方为正
omega_z：俯视机器人时逆时针为正

加速度定义：

ax > 0：机器人向前加速，载荷向后轮转移
ax < 0：机器人向后加速或前向刹车，载荷向前轮转移

ay > 0：机器人向右加速，载荷向左轮转移
ay < 0：机器人向左加速，载荷向右轮转移

轮序统一为：

[FL, FR, RR, RL]

含义如下：

缩写含义
FL左前轮
FR右前轮
RR右后轮
RL左后轮

所有四轮数组均遵循该顺序。

5. 快速使用

5.1 启动前准备

将所有 .m 文件放在同一个 MATLAB 工作目录下。

注意文件名必须和函数名一致，不要保留下载产生的 (1)、(2) 后缀。

错误示例：

Swerve_UI_Dashboard(1).m
Swerve_Dynamics_Core(2).m

正确示例：

Swerve_UI_Dashboard.m
Swerve_Dynamics_Core.m

5.2 推荐首次运行流程

在 MATLAB 命令行中执行：

clear classes; clear functions; clc;
Swerve_PhysicsConsistency_Test
Swerve_Debug_SmokeTest
main
Swerve_UI_Dashboard

各命令作用如下：

命令作用
clear classes; clear functions; clc;清除 MATLAB 缓存
Swerve_PhysicsConsistency_Test检查载荷转移和运动学方向是否正确
Swerve_Debug_SmokeTest检查项目各模块是否能正常运行
main输出命令行评估报告
Swerve_UI_Dashboard打开图形化交互界面

7. 额定扭矩与当前扭矩

Dashboard 中同时显示额定扭矩和当前工况扭矩。

额定扭矩

额定扭矩对应稳态巡航工况：

保持当前速度指令
前向加速度 ax = 0
右向加速度 ay = 0
转向角加速度 alpha_steer = 0

它适合用于估算连续运行下的基础扭矩需求。

当前扭矩

当前扭矩对应 Dashboard 输入的完整当前工况：

vx, vy, omega_z, ax, ay, dt

它更适合用于估算瞬态加速、横移、斜向爆发或急转时的峰值需求。

通常：

当前峰值扭矩 >= 额定巡航扭矩

8. 轮胎包胶建模

当前版本显式引入了轮胎包胶厚度：

轮子外半径 = swerve_wheel_radius
包胶厚度 = swerve_rubber_thickness
轮毂等效半径 = 轮子外半径 - 包胶厚度

动力学核心会计算：

  • 轮胎下压形变；
  • 接触半长；
  • 包胶压缩率；
  • 包胶触底风险。

当轮胎下压接近包胶厚度时，说明包胶可能已经接近压到底，此时线性弹性估算的可信度会下降，实际机器人可能出现硬接触、振动或抓地突变。

9. 结果如何理解

抓地利用率

抓地利用率 = 当前轮子所需合力 / 当前轮子最大摩擦力

简化判断：

抓地利用率含义
< 0.5抓地裕度较大
0.5 ~ 0.8抓地利用明显
0.8 ~ 1.0接近摩擦极限
> 1.0当前简化模型下判定为打滑

轮胎下压

轮胎下压用于观察包胶压缩情况。

需要注意：

  • 下压图是可视化示意图；
  • 图中形变量会被放大以便观察；
  • 数值标注仍是实际计算值；
  • 该模型不是高精度轮胎有限元模型。

为什么选择 Wheel-Leg 没有结果？

当前 Wheel-Leg 只是预留入口，尚未实现轮腿运动学和动力学模型。

11. 项目限制

当前项目采用简化准静态模型，主要假设包括：

  • 机器人为刚体；
  • 地面为水平面；
  • 不考虑悬架动态；
  • 不考虑轮胎侧偏角动态；
  • 不考虑轮胎滑移率动态；
  • 不考虑电机转矩-转速曲线；
  • 不考虑电池压降；
  • 不考虑电调限流；
  • 不考虑电机热衰减；
  • 不考虑完整四轮力分配优化；
  • 不考虑完整车体绕 Z 轴动力学平衡；
  • 轮胎包胶形变模型为简化线性估算。

因此，本项目结果应作为早期工程估算和方案比较参考，最终设计仍需结合实车测试进行校准。
