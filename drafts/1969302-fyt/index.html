简介

为了方便调试和使用，研制一款能满足底盘、机械臂、自定义控制器需求的通用主控板。

电源设计

增加了缓启动、防过压、防反接功能，为主控提供充足的保护。

其设计思路主要参考DJ的C板的保护电路。细节如下：

防反接设计

  1. 采用NMOS管体二极管续流方案，当电源正接时，通过GS压差自动开启NMOS管，实现极低导通压降的防反接保护
  2. 相比传统二极管方案（正向压降约0.4-1.1V），此设计显著降低了功率损耗。在栅极上加入稳压电阻和二极管，防止压差过大烧毁栅极。

过压保护设计

  1. 通过稳压二极管+分压电阻组合实现可调过压保护阈值
  2. 稳压二极管D3反向击穿后，将PNP管Q2的基极电位钳制在设定值（如28V），使Q2导通并关闭PMOS管Q1，切断输出
  3. 在栅极上加入稳压电阻，防止压差过大烧毁栅极。
  4. 创新点：在稳压二极管前加入分压电阻R84，通过调整该电阻值可灵活设定不同过压保护阈值，适应多种应用场景

缓启动设计

  1. 利用C4电容与R7/R8电阻组合实现渐进式电压上升接通瞬间Q2PNP导通，Q1PMOS栅极通过Q2和R7迅速达到VCC_BAT，随着C4充电完成，PMOS管栅极电位逐渐降低至阈值以下，实现平滑启动，有效避免了大电流冲击，保护后级电路元件
  2. 上下电曲线平缓，无过压和电压尖峰。线性化良好，无震荡，无平台期。缓启动时间适中，约30ms上下电电压图如图所示

电压采样

在保护电路后端加入电池电压采样，避免无保护的采样导致MCU烧毁避免了电池欠压对电池和用电设备的损害

供电设计

开关电源将输入的电压转为5v，选型及其优势详见电源的选型ldo将5v转为3.3v，为MCU及外设供电。

MCU及外设

MCU提供的资源如下：

  • 三路CAN总线：支持高速数据传输，适用于电机控制和设备间通信
  • 五路串口：满足多设备连接需求，支持UART/USART通信，其中一路串口专为遥控器的接收机设计
  • 一路USB接口：便于连接上位机进行调试和数据传输
  • 两路PWM波：用于舵机控制和电机调速，提供精确的脉宽调制能力
  • 板载陀螺仪为能简便的获得底盘位置，便于姿态控制，设计详见pcb设计

专为遥控器的接收机设计的串口的特殊说明

因为遥控器的接收机采用SBUS协议进行数据传输，这带来了两个挑战
  1. 逻辑反相 SBUS协议采用反向逻辑，即低电平代表逻辑“1”，高电平代表逻辑“0”。这与MCU的UART接口所使用的标准UART协议（正逻辑）完全相反。
  2. 电平转换 接收机输出的SBUS信号电平是5V，而主控板上使用的STM32H7 MCU的引脚仅能承受3.3V电压。直接连接会因过压而损坏MCU。

经典的NPN三极管共发射极开关电路，能同时完成反相和电平转换的任务。

硬件连接方式
  • 接收机信号 → 通过一个限流电阻 → 连接到NPN三极管的基极 (B)
  • NPN三极管的发射极 (E) → 直接连接到地 (GND)
  • NPN三极管的集电极 (C) → 通过一个上拉电阻连接到3.3V电源，同时连接到MCU的UART RX引脚。
信号转换过程
  1. 当接收机输出高电平 (约5V) 时三极管导通，集电极C与发射极E之间近似短路。MCU的RX引脚通过导通的三极管被拉到低电平 (0V)。结果：接收机的高电平（逻辑0）被转换为MCU可识别的低电平（逻辑0）。实现了逻辑反相和电平转换。
  2. 当接收机输出低电平 (约0V) 时三极管截止，集电极C与发射极E之间断开。MCU的RX引脚通过上拉电阻被拉到高电平 (3.3V)。结果：接收机的低电平（逻辑1）被转换为MCU可识别的高电平（逻辑1）。同样实现了逻辑反相和电平转换。
  3. 通过这个简单的电路，就将接收机输出的5V反相逻辑信号，安全、准确地转换成了MCU能够直接接收的3.3V正逻辑UART信号。

pcb设计

四层板结构

采用信号-地-电源-信号的分层结构（Top-GND-Power-Bottom）完整地平面确保每个信号层都有低阻抗回流路径，减少电磁干扰电源平面与地平面紧密耦合，形成分布电容，有效降低电源阻抗

关键元件布局

陀螺仪独立区域：远离发热元件，仅保留可控加热电阻，确保温度稳定，避免了温漂带来的误差。挖槽在很大程度上减少了震动带来的跳变误差。

晶振包地：远离其他元件，避免时钟信号受到干扰，提高系统稳定性

敏感信号隔离：对模拟信号和数字信号进行分区处理，减少串扰

交付使用情况

在底盘的调试过程中展现了极高的稳定性、交付至今无系统性故障。

CAN芯片失效、接收机连接问题这两个偶发性故障均及时解决，无遗留问题。

综述

在主控的设计上，以不牺牲稳定性为前提，小型化一直是努力的方向。

基于这点，除了接口之外，全部避免了插件的使用，大大提高了功率密度和空间利用率。

MCU的选型

STM32H723VGT6的选用有两个核心的需求：

需求一：缓解CAN资源的紧缺

因为必须占用一路CAN来进行可靠的控制板之间的通讯，所以只有两路CAN资源的MCU（例如之前使用的STM32F407系列）实际上只能使用一路CAN来带载七个电机（极限情况），这对于多达8个电机的舵轮底盘来说捉襟见肘。

而STM32H723VGT6有着三路CAN，这使得它在电机的带载能力上有着质的飞跃，避免了将底盘的控制任务拆分到两个MCU上，也提高了系统的稳定性。

需求二：视觉兑换和舵轮控制给MCU性能带来的挑战

这两项需求对MCU的性能提出了更高的要求，而STM32F407难以胜任。

与STM32F407相比，STM32H723VGT6 作为一款基于 Cortex-M7 内核的高性能微控制器，在多个方面实现了显著的升级和超越。

处理能力

H723: 搭载 Cortex-M7 内核，主频高达 550 MHz，处理性能可达 1177 DMIPS。

F407: 采用 Cortex-M4 内核，主频为 168 MHz，处理性能约为 210 DMIPS。

优势：H723 的 CPU 性能是 F407 的 5 倍以上，且 M7 内核的双精度 FPU 和更先进的架构在处理复杂算法和浮点运算时优势更为巨大。

存储资源

H723: 配备 1 MB Flash 和总计 564 KB 的 SRAM，并拥有独立的 32 KB 指令缓存和 32 KB 数据缓存，可实现从闪存执行代码时的零等待状态。

F407: 同样有 1 MB Flash 版本，但 SRAM 仅为 192 KB，且没有 L1 缓存。

优势：H723 不仅 RAM 容量更大，其 L1 缓存设计彻底消除了高频运行时的存储器访问瓶颈，大幅提升了实际运行效率。

图形处理

H723: 内置 Chrom-ART Accelerator™ 图形加速器和 LCD-TFT 控制器，专门用于加速图形界面的绘制。

F407: 无专用图形硬件加速功能。

优势：H723 能够轻松驱动更复杂的图形用户界面（GUI），而无需消耗大量 CPU 资源。

电源的选型

tps5430的大幅涨价促使了我们对于电源IC选型的重新考虑，而最新选择的MP9943 相较于 TPS5430 的主要优势体现在以下几个方面：

同步整流技术带来的高效率
  • TPS5430: 采用非同步整流架构，必须外接肖特基二极管进行续流。该二极管存在固定的正向压降（约 0.3V-0.6V），在大电流或低压差工作时会产生显著的导通损耗，导致芯片发热严重，效率较低。如图所示，纹波高达170mV

  • MP9943: 采用同步整流技术，内部集成了高/低侧 MOSFET，用 MOSFET 替代了续流二极管。MOSFET 的导通电阻（Rds(on)）极低，其导通损耗远小于二极管，因此整体转换效率更高，温升更低，尤其在轻载和低输出电压场景下优势更明显。

超小尺寸与高功率密度
  • TPS5430: 采用 8 引脚 SOIC PowerPAD 封装，尺寸较大。加上必须外接的电感、二极管等元器件，整体方案占用的 PCB 面积非常可观。
  • MP9943: 采用紧凑的 QFN 封装（如 3mm x 3mm 或 4mm x 4mm），体积远小于 TPS5430。同时，由于其高集成度和高达 2MHz 的开关频率（TPS5430 为 500kHz），可以使用更小的外部电感和电容。这使得整体解决方案尺寸大幅缩小，功率密度极高，非常适合空间受限的便携式设备。
优异的轻载效率与低静态功耗
  • TPS5430: 主要针对工业连续负载设计，轻载效率相对较低。其静态电流在微安级别，不适合对电池续航要求极高的应用。
  • MP9943: 专为电池供电设备优化，支持 PFM/PWM 自动切换模式。在轻载时自动进入 PFM 模式，通过降低开关频率来减少开关损耗，从而显著提升轻载效率，延长电池续航。
更高的智能化与可靠性
  • TPS5430: 功能相对基础，主要提供电压转换和基础的过流、过温保护。
  • MP9943: 集成了更丰富的功能，如电源正常指示（Power Good）信号，可用于系统监控；支持外部时钟同步；并提供更完善的保护机制（如逐周期限流、热关断等）。部分版本还通过了 AEC-Q100 车规级认证，在高温、高湿、振动等恶劣环境下的可靠性更高。

可以看到，MP9943在安全性、功耗优化和小型集成化上有着显著的优势，同步整流技术提供的更低纹波供电也是选型的缘由之一。

CAN收发芯片的选型

MAX3051在功耗与封装上的优势极大，这使我们重新考虑了选型，细节如下

  • 关断模式：MAX3051 独有的一个特性是关断模式（Shutdown Mode），在此模式下，发送器和接收器均关闭，功耗极低（<1μA），非常适合需要严格控制待机功耗的设备。
  • 封装形式：MAX3051 提供 SOT23 封装，这是其一大优势，因为 SOT23 是一种超小型封装，占用 PCB 面积极小，适合对空间要求极为苛刻的设计。SN65HVD230 通常采用 SOIC-8 封装。
