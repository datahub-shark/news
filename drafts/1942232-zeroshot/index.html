Chuyên mục: Thị giác máy

仓库链接：HargereavesQin/bit-auto-label: Robomaster Auto-labeling tool via sam

前言

目前基于 ONNX 的自动标注脚本存在明显痛点：先前的半自动流程通常先手动标注几十张或一百多张数据，再训练得到粗糙的 .pt / ONNX 模型做粗标，随后人工微调；或直接基于成熟 YOLO 网络标注。对 detect 类任务，bounding box 鲁棒性高、易于收敛，效果较好；但对精度要求更高的 pose 任务，仅靠数十至数百张手动标注很难让关键点精准收敛。这导致手动拖动漂移点的时间开销很大，眼力负担也重，体验相较纯手动标注提升有限。因此我们尝试构建更接近 zero-shot 的方法，尽量少依赖初始标注信息。


项目覆盖对象

  • Car-pose（装甲板位姿）
  • Car-detect（装甲板检测）
  • Radar-detect（雷达）
  • Buff-pose（能量机关）

本系统基于 PySide6 与 SAM3 构建，使用 Python 开发，专为 RoboMaster 装甲板数据集标注设计。核心功能包括智能点选、多边形标注、位姿标注，以及内置数据集处理工具。系统架构高度模块化，支持二次开发与定制扩展。


基于模糊语义掩码的 Zero-Shot 自动标注原理

核心矛盾在于：仅靠少量手动标注时，框与点往往不够准。我们首先考虑传统视觉——轮廓提取精度很高，但易受曝光与颜色影响，超参数调参成本高，且对关键点微调任务精度仍不足。因此转向更端到端的方案：用更强的视觉—语义模型替代传统视觉。

Meta 的 SAM 可理解为可提示的实例分割能力；SAM 3 进一步增强了文本开放词表能力，能够把目标轮廓较精准地分割出来，有利于替代传统视觉完成泛化轮廓提取，适合提升 pose 任务精度。就识别能力而言，文本提示也使 SAM 3 明显更强。我们实测直接使用提示词 "robot-car"，在约 2100 万像素的雷达图片数据集上完成车辆 detect（由 SAM 轮廓得到外接 bounding box）完全可行。同时，detect 模型也可作为 pose 工作流的辅助：相对 pose，detect 可基于少量数据收敛且标注更轻松，能在 SAM 分割失败时提供 ROI，兜底引导 SAM 重新寻找精确轮廓。

说明：整体链路更接近「弱监督 / 少标注驱动、半 zero-shot」，而非严格意义上的纯 zero-shot——尤其 Buff 任务中常先用 detect/ONNX 给出 ROI，再由 SAM 3 精修轮廓。


能量机关 Workflow 设计

能量机关对 pose 精度要求极高，训练又高度依赖颜色与梯度一致性，一直是自动标注鲁棒性的重灾区。队内第一种方案是：只标注扇叶内部五个点，结合粗略 detect 模型给出 ROI，或直接使用 Meta SAM 3 的文本提示做实例分割，将 bounding box 内的粗标图案分割为高精度边界；再在实例轮廓上做极值 / 主轴（PCA）分析，得到长短轴两端点，据此微调关键点位置。由于 detect 用极少图片即可收敛、标注简单且推理相对更快，批量标注时我们实际采用「detect 先做 ROI，再在区域内找轮廓精确极值」。该流程也适用于纯 ONNX 权重的标注微调：例如先用 YOLO 初级 pose 模型粗标，再用 SAM 基于分割结果做位置精修。

后期我们又试验了一版：标注 R 标中心 + 靶子后四点的五点 pose 模型。对 R 使用 red-R / blue-R 批量语义预提示，让 SAM 直接分割出 R 的精确边界，解算几何中心，再沿前述极轴思路求解后四个点。


Benchmark（800 张非同源数据集）

单张效果：纯自动标注（基于约 50 张手动关键点训练）时，有一定概率出现 5 个点相对期望位置整体漂移，偏离大于 4 px；若把「少于 5 个点也必须微调」计入，大约 300/800 张需要干预，良品率不到 50%。不同角度符面的偏差噪声差异也较大。

同批图片在加入 SAM 自动分割精修后效果更好：几乎未再出现四个点同时完全漂移；约有 80 张存在 2 个及以上关键点漂移大于 2 px，对应约 800 张中需返工比例低于 10%，可接受为后续少量手动微调。虽与理想端点仍有误差，但整体趋势方差更小。

ArmorLabel：基于 SAM3 的装甲板标注系统

功能：

  1. 视频抽帧工具
  2. 针对 YOLO-Pose 的数据集处理工具
  3. 支持 Pose 标注
  4. 装甲板半自动标注
  5. 装甲板全自动标注
  6. 自动求解关键点（kpts），降低人工点选方差
  7. 类别与实例管理

作用：

  1. 通过提示词 "number" 与 "light"，实现装甲板半自动 / 全自动标注，显著提升效率。
  2. 半自动与全自动流程中，由几何方法求解 kpts，减少手抖式点选误差，提升标注一致性（仍建议抽检）。
  3. 对新场景、新类别（如血条、雷达整车、无人机等），可直接用 SAM 3 自动给出 bbox，再人工微调框的位置与大小，兼顾效率与质量。实测可输入 car 识别 RM 车辆并生成 bbox 或边缘多边形。
  4. 内置可视化视频抽帧工具，支持双帧预览、时间范围选择等。

1.0部署与运行环境

软件本体：

git clone https://github.com/HargereavesQin/bit-auto-label.git

建议同时初始化子模块（否则 sam3/ 可能为空）：

git clone --recurse-submodules https://github.com/HargereavesQin/bit-auto-label.git


1. 1环境依赖


推荐 Python 3.10+（本仓库实测可用 3.13）。Torch 建议按 CUDA 版本手动安装后再装其余依赖：

pip install -r requirements.txt

1.2 模型下载与配置

  • SAM3 官方源码：https://github.com/facebookresearch/sam3
  • sam3.pt 官方权重：https://huggingface.co/facebook/sam3/tree/main
  • 百度网盘（可选）：链接 https://pan.baidu.com/s/10RHfhyqiKNe1PyzpoJI-ww?pwd=dpk1 ，提取码 dpk1

将权重放到 models/sam3.pt。

1.3 启动系统

python main.py

1.4类别
使用 RM-Mode 可自动加载 14 类兵种（若 2027 重装调整为 12 类；若 YOLO 不分类而与 MLP 解耦，也可收敛为 2 类）。


用户操作指南

常用功能

  • A / D：切换图片
  • 右键：删除标注
  • U：切换到 Pose 模式

  • 需存在 models/sam3.pt 才会启用 SAM
  • 需打开 SAM 开关才会启用辅助

视频抽帧工具 UI

TODO & ISSUE

  1. 仍存在检测失败SAM 分割有时对与图案重合的大面积光晕敏感；此时用粗略 detect 模型提供 ROI 往往更稳妥。
  2. 时间开销符在 SAM 视角下，一个 bounding box 内常含两个分割实例，需要邻域检测才能正确应用极轴逻辑，否则五点易落到靶心轮廓团上；邻域检测带来额外耗时。
  3. LoRA 特化增强尚未充分验证基于 RoboMaster 数据的 LoRA-SAM（如 buff-red / buff-blue）能否通过语义直接找到精确轮廓；国赛期间有过尝试，经验不足，后续可能继续研究。
  4. 建议对新出现、尺寸小、语义易受环境影响的目标类别，可优先考虑用 Blender 批量生成虚拟数据。可参考同济 SuperPower 与港科大 Enterprise 的方案。
