16DOF 轮足机器人强化学习训练、MuJoCo 仿真与 Sim2Sim 验证工程开源

开篇

大家好，我们是山东华宇工学院 HYNova 战队。本项目整理轮足机器人的软件部分，公开从 MJCF 机器人模型、mjlab 强化学习训练，到 MuJoCo 独立仿真和 Sim2Sim 策略验证的代码，方便其他队伍理解从仿真模型到实机部署前验证的完整流程。github完整项目入口

实机部署、ROS 2/C++ 控制主线、比赛任务集成和打点工具已整理在RC_Legged_Control 项目。机械图纸见[山东华宇工学院16DOF机械开源]。全套完整开源见RC_WheelLeg轮足全开源

本次开源内容

  1. rc_mjlab/src/robot/：基于 mjlab 的四轮腿混合机器人训练任务，包含 Flat、Rough、Crawl 三类任务。
  2. rc_mjlab/mjcf/：机器人 MJCF、场景入口和 STL 网格文件。
  3. rc_mjlab/sim2sim/：策略回放、交互式 MuJoCo 3D 仿真、二维导航面板和竞赛地形验证。
  4. rc_mjlab/mujoco_sim/：独立的运动学、动力学和 MPC 调试工具。
  5. model_rough.pt、model_crawl.pt：用于本地回放和接口验证的示例策略权重。
  6. pyproject.toml、uv.lock：Python 项目依赖和锁定版本。

训练设计概览

机器人为 4 条轮腿，每条腿包含 3 个腿部关节和 1 个驱动轮，共 16 个执行器。训练中使用 MuJoCo 进行物理仿真，策略决策频率为 50 Hz，物理步长为 2 ms。训练任务包含速度跟踪、姿态稳定、关节限位、碰撞、动作平滑和能耗等约束，并加入摩擦、质量、执行器、传感器偏置和持续扰动等随机化因素。

Rough 任务包含台阶、粗糙地面、高墙和斜坡等竞赛相关地形；Crawl 任务用于限高和爬坡场景。具体奖励权重、课程和随机化范围请以 rc_mjlab/README.md 与 src/robot/ 配置为准。

快速开始

cd rc_mjlab
uv sync
uv run train Robot-Flat-v0
uv run train Robot-Rough-v0
uv run play Robot-Rough-v0

首次运行前请确认本地已安装可用的 PyTorch、MuJoCo、mjlab、图形环境和对应 CUDA 驱动。不同机器上的 GPU 和依赖版本可能导致训练速度及回放效果不同。

Sim2Sim 与仿真回放

cd rc_mjlab
uv run python sim2sim/sim2sim.py
uv run python sim2sim/nav_sim2sim.py
uv run python mujoco_sim/run.py

Sim2Sim 入口会读取本目录的 mjcf/、sim2sim/terrain/ 和策略权重。

与实机部署的关系

训练与仿真负责策略学习、模型检查和部署前回放；实机部署负责传感器接入、电机映射、CAN 通信、安全检查、导航和比赛任务调度。两部分必须核对观测顺序、动作顺序、关节方向、零位、缩放和控制频率，不能仅凭仿真能运行就直接上电。

实机和比赛集成代码请查看RC_Legged_Control 项目

复现建议

建议按以下顺序验证：先运行 MuJoCo 独立模型，再回放 Flat/Rough/Crawl 策略，随后检查 Sim2Sim 的观测和动作接口，最后再与实机部署工程逐项核对。首次上车前应架空机器人，确认急停、关节方向、零位和限位。
