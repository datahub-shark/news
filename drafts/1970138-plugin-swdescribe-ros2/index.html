大家好啊，最近我们遇到了一些solidwork导出urdf的性能问题，如果不简化模型的话，导出的等待时间将会非常长，而且非常容易崩溃，我们的机械之前导出的时候被折磨的半死，所以我就开发（vibe）了这个插件。

插件开源以及下载：点击这里


基本功能：

1. 快速STL导出

在导出一个完整且未简化的轮腿模型（不包含STL修复）仅仅需要0.43s

这个速度非常快，其中的原因是这个项目的stl文件导出是直接读取的用于着色显示的三角化数据，而不是每次都调用 SolidWorks 的 STL SaveAs 导出器。对于SW的COM接口来说，SaveAs导出器要求待转换文档必须是 Active Document这就意味着导出器几乎只能处理当前已经打开并且选中的文档，很难把大量零件同时交给导出器，导致零件几乎只能一个一个导出，效率较低。而我目前的操作是直接跳过了导出器，直接读取SW用于渲染的三角化数据，这使得导出速度非常快。

2. STL精度调整和优化

一些仿真软件对于模型面数有一定要求，这个插件也提供了stl的面数上限设置和QEM优化。

3. 输出URDF预览

本插件提供URDF的基本预览功能，能够让你知道最终输出的面数和各link/joint关系。同时，预览界面也支持缩放/拖动、旋转操作操作，这些操作和SW的键位保持一致。

注意：预览窗口和SW中机器人的位姿不能直接等同于导出URDF中的位姿，因为对于Revolute 关节，父子 Link 重叠在一起为零点。也就是说，如果你把导出的URDF文件直接导入Mujoco中，各个link有可能是重叠的（默认状态q=0）。为了解决这个问题，插件提供了view_sw_pose.py，来记录此时SW中机器人的位姿信息。

4. 快速创建虚拟Link

如果需要虚拟Link，直接点击“新建子Link”即可，插件会默认创建一个空Link

5. Mujoco和ROS2支持

本插件导出的URDF格式支持Mujoco和ROS2两种格式

URDF 使用相对网格路径，并写入 <mujoco><compiler .../></mujoco> 设置以保留路径和视觉几何；同时设置极小的质量和惯量下限，使作为参考框架使用的空 Link 即使带活动关节也能被 MuJoCo 加载。编译器还启用 balanceinertia：当 SolidWorks 返回的主惯量违反刚体三角不等式时，MuJoCo 会平衡该异常张量，而不会拒绝整个模型。当前输出仍是 URDF，不直接生成 MJCF。URDF 标准没有非零“默认关节状态”；直接加载 robot.urdf 仍从 q=0 开始。运行 view_sw_pose.py 会在加载后写入导出时计算的关节角，使 MuJoCo 首次显示与 SolidWorks 当前装配姿态一致。

6. 导出STL修复

在导出的SW工程中，可能一些零件为STEP，而这些STEP或是零件本身在SW解析时可能是正常的，但是在导出成STL之后可能会出现“非流性边缘”和“开放曲面”的问题。针对这个问题，本插件也提供了解决方案：

  1. 提供基础的破面修复
  2. 使用SolidWork原本的STLSaveAs导出器来导出。但是经过试验，这一步通常不会有很大作用。如果破面修复无法解决，大部分情况为原本零件出现问题。如果这些破面不影响仿真，可以考虑保存，而不修复。

插件坐标系与参考轴：

在 SolidWorks 中通过 插入 → 参考几何体 创建并命名坐标系或轴：

  • 顶层装配体、子装配体和零件内部的坐标系都可作为 Link frame；位置和方向会自动换算到根装配坐标。
  • 活动关节可选择 SolidWorks 自建参考轴；
    • 对于Revolute，它会成为关节局部 +Z 并据此定向关节坐标系
    • 其他关节会转换为当前 Link 坐标系中的局部 XYZ。关节原点仍由所选坐标系（或手工 XYZ）决定。
  • Revolute 关节统一以关节局部 +Z 为正轴，从 +Z 端看向原点时逆时针为正；“最小夹角 / 最大夹角”表示子 Link 相对父 Link 的有符号角度。
    • q=0 由连续三个关节中心定义：在关节 Z 轴的法平面内，将“当前关节 → 子级关节”折回并对齐到“当前关节 → 父级关节”，即父子 Link 重叠在一起为零点 q=0 ；
    • 末端没有子级关节时使用 Link 质心方向。导出时会单独构造这一 URDF 零位 frame，因此 lower / upper 就是这里填写的绝对夹角；
    • 捕获时的SolidWorks中的机器人状态仅用于网格信息、惯量和重新编辑数据。
  • 选择 Prismatic 后显示可编辑的“初始位置（m）”
    • 插件优先读取已识别 Slider/距离配合的当前距离；
    • 配合没有可用尺寸和参考点时显示 0。该值表示SW中此时 Prismatic 伸出的距离为 q_SW，可覆盖；导出时据此反推 Prismatic 的 q=0 时的状态。
