1. Giới thiệu dự án

RM-MotorBench là bàn thử nghiệm động cơ phục vụ phòng Lab nghiên cứu robot: Người dùng có thể trực tiếp thêm động cơ trên giao diện web theo ID gạt mã của ESC (bộ điều tốc), thiết lập tốc độ quay mong muốn. Lệnh điều khiển sẽ được truyền qua cổng nối tiếp ảo USB (USB Virtual COM Port) xuống bo mạch phát triển để lái động cơ qua bus CAN, đồng thời các thông số vận tốc, dòng điện, nhiệt độ được phản hồi theo thời gian thực.

Điểm đặc biệt: Thay động cơ không cần sửa code, không cần nạp lại firmware, thao tác cực kỳ đơn giản (rất thích hợp cho việc test nhanh cơ cấu gạt đĩa nạp đạn của robot).

Xem nguyên văn tiếng Trung (原文)

RM-MotorBench 是一个面向实验室的电机测试台：网页上按电调拨码 ID 现场添加电机、设转速，指令经 USB 虚拟串口下发到开发板驱动 CAN 电机，转速/电流/温度实时回传。换电机不改代码、不烧固件，傻瓜操作，如拨弹盘的快速测试。

2. Các tính năng cốt lõi (Core Features)

  • Thay động cơ không cần nạp lại firmware: Cho phép thêm/xóa động cơ linh hoạt ngay khi đang chạy: hỗ trợ động cơ DJI M3508, M2006, GM6020 và động cơ Damo (达妙) DM4310, DM8009P.
  • Hỗ trợ 3 dòng bo mạch phát triển: Mã nguồn mở firmware (CubeMX + CMake) cho bo mạch DJI Type A, DJI Type C và Damo MC02; tất cả đều kết nối chung một phần mềm máy tính (Host UI).
  • Chuyển đổi 3 vòng điều khiển linh hoạt: Hỗ trợ chuyển đổi trực tiếp giữa vòng Vận tốc (Speed), Vị trí (Position) và Dòng điện (Current). Căn chỉnh thông số PID trực tiếp trên Web và ghi tức thì vào bộ nhớ động cơ.
  • Tích hợp sẵn các công cụ đo kiểm:
    • Vẽ đồ thị đáp ứng thời gian thực (Real-time curve).
    • Chế độ tự động xuất tín hiệu sóng Sin hoặc hàm bước nhảy (Step response).
    • Công cụ tính toán quy đổi giữa tần số bắn (ROF) và tốc độ quay động cơ.
    • Thử nghiệm vị trí đĩa cấp đạn bắn đơn (Single shot) hoặc bắn đôi (Double shot).
  • Cơ chế bảo vệ an toàn:
    • Cơ chế nhịp tim (Heartbeat): Mất kết nối quá 1.5 giây sẽ tự động ngắt toàn bộ động cơ.
    • Khi chưa ấn Enable (Kích hoạt), động cơ hoàn toàn không phát lực.
    • Phím cách (Spacebar) đóng vai trò phím dừng khẩn cấp (E-Stop).
Xem nguyên văn tiếng Trung (原文)
  • 免烧固件换电机：动态添加/删除大疆 M3508 / M2006 / GM6020、达妙 DM4310 / DM8009P
  • 三板支持：大疆 A 型、C 型、达妙 MC02 固件均开源（CubeMX + CMake），上位机同一套
  • 速度/位置/电流三环在线切换，PID 网页整定并写入电机
  • 测试工具内建：实时曲线、正弦/阶梯自动输出、射频→转速计算器、单发/双发拨弹位置测试
  • 安全设计：心跳断链约 1.5s 自动全停、未使能不出力、空格急停

3. Hướng dẫn bắt đầu nhanh (Quick Start)

  1. Nạp firmware xuống bo mạch: Cài extension STM32CubeIDE for Visual Studio Code trong VS Code, mở project tương ứng với bo mạch đang dùng và nhấn F5 để biên dịch và nạp code.
  2. Khởi chạy phần mềm máy tính (Host App):
    • Cách 1: Chạy trực tiếp file MotorBench-1.2.0-Windows-x64.exe (không cần cài môi trường).
    • Cách 2: Chạy qua mã nguồn: mở terminal gõ npm install && npm start rồi mở trình duyệt truy cập http://127.0.0.1:3000.
  3. Thao tác điều khiển trên Web: Chọn cổng nối tiếp (COM Port) $\rightarrow$ Bấm ＋ Thêm động cơ (chọn Model động cơ / Bus CAN / ID gạt mã ESC) $\rightarrow$ Bấm Bind (Liên kết) $\rightarrow$ Bấm Enable (Kích hoạt) $\rightarrow$ Kéo thanh trượt để quay động cơ.
Xem nguyên văn tiếng Trung (原文)
  1. 烧固件：VS Code 装 STM32CubeIDE for Visual Studio Code 扩展，打开对应板子工程按 F5
  2. 起上位机：双击 EXE（或 npm install && npm start 后开 http://127.0.0.1:3000）
  3. 网页选串口 → ＋ 添加电机（型号/总线/电调拨码 ID）→ 绑定 → 使能 → 拖滑块

4. Cảnh báo an toàn khi đấu dây

Trước khi cấp nguồn, hãy kiểm tra thật kỹ: Cắm ngược jack XT30, đảo lộn dây CAN High / CAN Low, chập ngắn mạch nguồn 24V — những lỗi này sẽ làm bốc khói linh kiện và tốn kém chi phí thay thế rất lớn.

5. Các hạn chế đã biết (Known Limitations)

  • Danh sách động cơ đã cấu hình không lưu qua các lần mất nguồn, khi bật nguồn lại cần thêm lại trên giao diện.
  • Giá trị thông số PID mặc định chỉ là mức khởi đầu để tham khảo, người dùng cần căn chỉnh lại theo tải cơ khí thực tế.
  • Trên cùng một bus CAN, dải ID phản hồi của gimbal motor GM6020 và motor M3508 / M2006 có thể trùng lặp một phần (giao diện web sẽ liệt kê danh sách các ID khả dụng để bạn chọn tránh xung đột).
