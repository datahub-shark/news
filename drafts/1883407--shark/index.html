项目简介

RMUC 2026 Registration Dashboard 是一套面向 RMUC 2026 志愿填报阶段的分析与可视化看板。

项目基于公开规则、公开战绩、积分信息、志愿快照和赛制路径，尝试把“当前赛区分布会导向什么结果”以更直观的方式展示出来。整体内容围绕同一套数据流组织，覆盖赛区调剂、综合实力分、晋级名额推演、瑞士轮样本展示、概率模拟和志愿决策分析。

主要功能

  • 晋级推演：查看当前志愿分布下三个赛区的调剂结果、名额边界和整体盘面。
  • 全局瑞士轮样本：展示一条可复现的样本赛程，用于观察分组、配对和资格结果。
  • 瑞士轮概率模拟：面向单支学校展示国赛、复活、出局、Top 8 / Top 4 等概率结果。
  • 赛区强度对比：从均分、中位数、头部竞争力和离散程度等角度比较不同赛区。
  • 综合实力榜：展示全局排序及分数构成，帮助理解后续推演结果的依据。
  • 志愿决策辅助：对不同志愿方案进行对比，查看落区、排位和晋级概率的变化。

适用场景

  • 想快速了解当前赛区盘面的队伍
  • 想比较不同志愿方案影响的学校
  • 对赛制推演、可视化分析和模型复现感兴趣的同学
  • 想围绕 RMUC 志愿填报开展技术讨论的社区成员

技术栈说明

本项目整体采用“Python 数据计算 + 原生前端静态展示 + GitHub Actions 自动更新”的方式实现，尽量保持结构直接、依赖简单，方便本地运行和后续维护。

主要技术栈包括：

  • Python 3.11+：用于完成志愿数据处理、赛区调剂、综合实力计算、晋级推演和瑞士轮模拟等核心逻辑。
  • 原生 HTML / CSS / JavaScript：用于实现前端看板页面，不依赖重量级前端框架，直接基于生成后的静态数据展示结果。
  • JSON / CSV：作为中间结果和前端展示数据的主要载体，便于生成、调试和复用。
  • GitHub Actions：用于手动触发数据刷新，自动重新生成看板所需文件并更新仓库内容。
  • 静态页面发布方式：前端内容集中在 docs/ 目录，便于静态托管和快速分享。

使用提醒

  • 本项目结论建立在当前快照、公开数据和建模假设之上，结果会随志愿变化而变化。
  • 看板中的预测结果仅供讨论和参考，不代表任何官方结论。
  • 如果需要用于实际判断，请务必结合官方公告、实时信息和队伍自身情况综合考虑。
